## Stack

- [Quartz v4](https://quartz.jzhao.xyz/) — Static site generator for Obsidian
- [Obsidian](https://obsidian.md/) — Markdown editor

## Local Development

```bash
# Install dependencies
npm install

# Start dev server
npx quartz build --serve

# Build for production
npx quartz build
```
