# 01. Phase 1 - IME 입력 보호 시스템

태그: #Phase1 #IME #Internationalization

## 목표: 아시아권 언어 입력 중 단축키 충돌 완전 차단

### 문제 상황: IME란 무엇이며 왜 문제가 되는가?

IME(Input Method Editor, 입력기)는 한국어, 일본어, 중국어처럼 키보드의 키 개수보다 글자 수가 훨씬 많은 언어를 입력하기 위한 시스템입니다.

예를 들어 '한'이라는 글자를 입력하려면 'ㅎ', 'ㅏ', 'ㄴ' 키를 순서대로 누릅니다. 이 과정에서 브라우저는 각 키에 대한 `keydown` 이벤트를 발생시킵니다. 만약 `a`키에 `전체 선택(Ctrl+A)` 같은 단축키가 할당되어 있다면, 'ㅎ' 다음 'ㅏ'를 누르는 순간 의도치 않게 단축키가 실행되는 끔찍한 경험을 하게 됩니다.

이처럼 글자가 **조합 중(Composing)**일 때 단축키가 실행되는 것을 막는 것이 이 단계의 핵심 목표입니다.

### 해결 방안: `isComposing`과 Composition Events

현대 브라우저는 이 문제를 해결하기 위한 표준적인 방법을 제공합니다.

1.  **`KeyboardEvent.isComposing`**: `keydown`, `keyup` 같은 키보드 이벤트 객체에 포함된 boolean 값입니다. IME가 글자를 조합 중일 때는 `true`가 되고, 조합이 끝나면 `false`가 됩니다. **이것이 가장 간단하고 핵심적인 체크포인트입니다.**

2.  **Composition Events**: 좀 더 정교한 제어를 위해, 조합의 시작, 변경, 종료 시점에 별도의 이벤트를 제공합니다.
    -   `compositionstart`: 조합이 시작될 때 발생합니다.
    -   `compositionupdate`: 조합 중인 글자가 변경될 때 발생합니다. (예: 'ㅎ' -> '하')
    -   `compositionend`: 조합이 완료되어 글자가 입력 필드에 확정될 때 발생합니다.

### 구현 전략

1.  **글로벌 상태 변수 관리**: 시스템 전역에서 IME 조합 상태를 추적하는 변수를 둡니다. (예: `let isIMEComposing = false;`)

2.  **Composition Event 리스너 등록**: `window`나 최상위 앱 컨테이너에 `compositionstart`와 `compositionend` 이벤트 리스너를 등록합니다.
    -   `compositionstart`가 발생하면 `isIMEComposing`을 `true`로 설정합니다.
    -   `compositionend`가 발생하면 `isIMEComposing`을 `false`로 설정합니다.

3.  **단축키 핸들러에서 상태 체크**: 모든 단축키를 처리하는 메인 핸들러 최상단에 가드를 추가합니다.

```javascript
// --- 전역 상태 관리 --- //
let isIMEComposing = false;

window.addEventListener('compositionstart', () => {
  isIMEComposing = true;
});

window.addEventListener('compositionend', () => {
  isIMEComposing = false;
});

// --- 메인 키보드 이벤트 핸들러 --- //
function onKeyDown(event) {
  // 1. isComposing 플래그를 직접 확인 (가장 간단한 방법)
  if (event.isComposing) {
    return; // 조합 중이므로 모든 단축키 로직을 건너뛴다.
  }

  // 2. 전역 상태 변수를 확인 (더 안정적인 방법)
  if (isIMEComposing) {
    return; // 조합 중이므로 모든 단축키 로직을 건너뛴다.
  }

  // 조합 중이 아닐 때만 단축키 처리 로직 실행
  if (event.ctrlKey && event.key === 'a') {
    // 전체 선택 로직 실행
  }
  // ... 기타 단축키들
}

window.addEventListener('keydown', onKeyDown);
```

이 간단한 로직만으로도 아시아권 사용자의 입력 경험을 극적으로 향상시킬 수 있습니다.
