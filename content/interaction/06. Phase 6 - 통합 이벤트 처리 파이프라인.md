# 06. Phase 6 - 확장된 이벤트 처리 파이프라인

태그: #Phase6 #Architecture #PuttingItAllTogether

## 목표: 모든 리스크를 고려한 robust한 이벤트 처리

지금까지 논의한 모든 보호 장치와 관리 시스템을 하나의 일관된 처리 흐름, 즉 **통합 이벤트 처리 파이프라인**으로 엮어내는 단계입니다. 이 파이프라인은 `keydown`과 같은 원시(raw) 이벤트가 발생한 순간부터 실제 액션이 실행되기까지의 모든 검문소를 정의합니다.

이 파이프라인의 목적은 **"잘못된 시간에, 잘못된 장소에서, 잘못된 액션이 실행되는 것을 원천 차단"**하는 것입니다.

### 통합 이벤트 파이프라인의 흐름

사용자가 키보드를 누르는 순간부터 아래의 과정이 순차적으로 진행됩니다. 각 단계에서 '통과'하지 못하면 파이프라인은 즉시 중단되고, 어떤 액션도 실행되지 않습니다.

**[이벤트 발생: `keydown`]**

1.  **➡️ Phase 1: IME 조합 중인가?**
    -   `if (event.isComposing) return;`
    -   **목적**: 한글 등 조합 언어 입력 시 단축키 충돌 방지.
    -   [[01. Phase 1 - IME 입력 보호 시스템]]

2.  **➡️ Phase 5: 올바른 인스턴스(탭)인가?**
    -   `if (instanceId !== getActiveInstanceId()) return;`
    -   **목적**: 여러 탭/창 중 활성화된 인스턴스에서만 동작하도록 보장.
    -   [[05. Phase 5 - 다중 인스턴스 라우팅]]

3.  **➡️ Phase 4: 키 반복 이벤트인가?**
    -   `if (event.repeat && !shortcut.allowRepeat) return;`
    -   **목적**: 키를 꾹 눌렀을 때 발생하는 불필요한 반복 실행 방지.
    -   [[04. Phase 4 - 성능 최적화]]

4.  **➡️ Phase 2: 현재 스코프는 무엇인가?**
    -   `const scope = ScopeManager.getActiveScope();`
    -   **목적**: 현재 UI 상태(모달, 에디터, 캔버스 등)에 맞는 스코프 결정. (내부적으로 캐싱 사용)
    -   [[02. Phase 2 - 계층화된 오버레이 스코프]]

5.  **➡️ 단축키가 존재하는가?**
    -   `const shortcut = findShortcut(event, scope);`
    -   **목적**: 현재 스코프에서 눌린 키 조합에 해당하는 단축키 액션 탐색.

6.  **➡️ Phase 3: 현재 포인터 타입에서 사용 가능한가?**
    -   `if (!shortcut.pointerTypes.includes(primaryPointerType)) return;`
    -   **목적**: 터치 환경에서 마우스 전용 단축키가 실행되는 것 방지.
    -   [[03. Phase 3 - 멀티 포인터 적응 시스템]]

7.  **➡️ 브라우저 기본 동작 차단**
    -   `event.preventDefault();`
    -   **목적**: `Ctrl+A`가 페이지 전체 텍스트를 선택하거나, `Space`가 페이지를 스크롤하는 등의 브라우저 기본 동작을 막고, 온전히 우리의 액션만 실행되도록 제어권을 가져옴. **(매우 중요!)**

8.  **➡️ 액션 실행**
    -   `shortcut.action();`
    -   **목적**: 모든 검문을 통과한 최종 액션을 실행.

**[파이프라인 종료]**

### 디버깅 및 모니터링

이처럼 복잡한 파이프라인은 문제가 발생했을 때 원인을 찾기 어려울 수 있습니다. 따라서 각 단계에서 어떤 결정이 내려졌는지 로그를 남기는 것이 매우 중요합니다.

```javascript
function unifiedKeyDownHandler(event) {
  console.log(`--- Event Pipeline Start: ${event.key} ---`);

  if (event.isComposing) {
    console.log('[STOP] IME composing.');
    return;
  }

  const scope = ScopeManager.getActiveScope();
  console.log(`[INFO] Current scope: ${scope}`);

  const shortcut = findShortcut(event, scope);
  if (!shortcut) {
    console.log('[STOP] No shortcut found for this scope.');
    return;
  }

  // ... 모든 단계에 상세한 로그 추가 ...

  event.preventDefault();
  console.log(`[EXEC] Running action: ${shortcut.name}`);
  shortcut.action();
}
```

이 통합 파이프라인 설계를 통해, 제안하신 모든 요구사항을 만족하는 견고하고 예측 가능한 프로덕션 레벨 스코프 관리 시스템의 청사진이 완성되었습니다.
