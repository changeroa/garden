# 05. Phase 5 - 다중 인스턴스 라우팅 시스템

태그: #Phase5 #Advanced #Multi-tab

## 목표: 여러 캔버스/탭 환경에서 정확한 이벤트 라우팅

### 문제 상황: "어느 창에서 실행해야 하죠?"

사용자가 브라우저의 여러 탭(Tab)에 우리의 웹 애플리케이션을 동시에 띄워놓고 작업하는 시나리오를 상상해 봅시다. 또는 하나의 페이지 안에 여러 개의 독립적인 캔버스(iframe)가 있는 경우도 있습니다. 이들을 각각 **인스턴스(Instance)**라고 부릅니다.

이때 사용자가 단축키 `Ctrl+S`를 누르면, 어떤 일이 벌어져야 할까요? 모든 탭에서 저장 기능이 실행된다면 큰일입니다. 오직 **사용자가 마지막으로 상호작용했던, 즉 활성화된 인스턴스**에서만 단축키가 동작해야 합니다.

### 해결 방안: 인스턴스 우선순위 매니저와 이벤트 라우팅

여러 인스턴스 중 어떤 인스턴스가 이벤트를 처리할지 결정하는 중앙 관제 시스템을 구축합니다. 핵심은 **"가장 최근에 사용된 인스턴스가 제어권을 갖는다"**는 규칙입니다.

1.  **인스턴스 우선순위 매니저 (Instance Priority Manager)**: 모든 인스턴스의 활동을 추적하고 현재 활성화된 인스턴스가 무엇인지 결정합니다.
2.  **Tie-Breaker**: 활성 인스턴스를 결정하는 기준, 즉 **최근 상호작용 시간(timestamp)**입니다.

### 구현 전략

이 기능은 브라우저 탭 간 통신 기술(예: `BroadcastChannel`, `localStorage`)이나 iframe 간 통신 기술(`postMessage`)을 필요로 하여 복잡도가 높습니다. 여기서는 `BroadcastChannel`을 이용한 탭 간 통신을 예로 들어 개념을 설명합니다.

1.  **고유 인스턴스 ID 부여**: 각 인스턴스(탭)는 시작될 때마다 고유한 ID를 생성합니다. (예: `instanceId = 'app-' + Math.random()`)

2.  **활동 내역 브로드캐스팅**: 각 인스턴스는 자신의 창에서 사용자의 상호작용(`focus`, `mousedown`, `keydown` 등)이 감지될 때마다, 자신의 ID와 현재 시간을 담아 모든 탭에 브로드캐스트(방송)합니다.

    ```javascript
    // 각 인스턴스(탭) 내부 로직
    const channel = new BroadcastChannel('shortcut_router');
    const instanceId = 'instance-' + Math.random();

    window.addEventListener('focus', () => {
      // 내가 활성화되었다고 모든 탭에 알림
      channel.postMessage({ type: 'INSTANCE_ACTIVATED', id: instanceId });
    }, true);
    ```

3.  **우선순위 매니저의 활성 인스턴스 결정**: 각 인스턴스는 다른 인스턴스로부터 오는 메시지를 수신합니다. 이 메시지를 통해 "현재 활성화된 인스턴스는 OOO이다" 라는 정보를 전역 변수에 기록합니다.

    ```javascript
    // 모든 인스턴스에 공통으로 들어가는 로직
    let activeInstanceId = null;

    channel.addEventListener('message', (event) => {
      if (event.data.type === 'INSTANCE_ACTIVATED') {
        activeInstanceId = event.data.id;
      }
    });
    ```

4.  **이벤트 라우팅**: 단축키 이벤트가 발생했을 때, 자신의 `instanceId`가 현재 `activeInstanceId`와 일치하는 인스턴스만이 단축키 로직을 실행합니다. 다른 인스턴스들은 이벤트를 무시합니다.

    ```javascript
    function onKeyDown(event) {
      // 자신의 ID가 활성 ID와 다르면 즉시 중단
      if (instanceId !== activeInstanceId) {
        return;
      }

      // ... IME 체크, 스코프 체크, 단축키 실행 로직 ...
    }
    ```

이러한 라우팅 시스템을 통해 여러 워크스페이스(탭, 창)를 열어두고 작업하는 파워 유저들에게도 완벽하고 예측 가능한 경험을 제공할 수 있습니다.
