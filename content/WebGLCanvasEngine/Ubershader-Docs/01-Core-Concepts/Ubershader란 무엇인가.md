## 📖 개념 설명
Ubershader는 **"만능 셰이더"**라는 의미로, 다양한 종류의 그래픽 객체(여기서는 사각형 노드)를 **단 하나의 WebGL 셰이더 프로그램**으로 렌더링하는 기법입니다.

전통적인 방식처럼 각 객체 타입마다 다른 셰이더를 사용하지 않고, 모든 렌더링 로직을 하나의 통합된 셰이더에 구현합니다. 이를 통해 GPU에 렌더링 명령(Draw Call)을 보내는 횟수를 획기적으로 줄여 CPU와 GPU 사이의 병목을 최소화하고 성능을 극대화합니다.

이 프로젝트의 Ubershader는 특히 SDF(Signed Distance Fields)를 사용하여 고품질의 둥근 사각형을 그리고, 인스턴스 렌더링(Instanced Rendering)으로 수많은 노드를 한 번에 처리하는 데 최적화되어 있습니다.

## 💡 실무 연결점
- 데이터 시각화, 노드 기반 편집기, UI 라이브러리 등 대량의 2D 객체를 효율적으로 그려야 하는 모든 곳에 사용됩니다.

## 💻 TypeScript 관점
이 프로젝트에서 Ubershader 개념은 `Ubershader.ts` 파일의 `UberShader` 클래스를 통해 구체적으로 구현됩니다.

- **중심 클래스**: `UberShader` 클래스는 셰이더 소스 코드를 내장하고, WebGL 렌더링 컨텍스트(`WebGL2RenderingContext`)를 받아 컴파일, 링크, 그리고 실행 상태를 관리하는 모든 책임을 집니다.
- **데이터 계약**:
  - `ShaderCompileResult`: `compile()` 메서드의 반환 타입으로, 셰이더 컴파일의 성공 여부, 컴파일된 프로그램, 오류 메시지, 소요 시간 등 명확한 결과물을 정의합니다.
  - `ShaderUniforms`: `setUniforms()` 메서드에 전달되는 데이터의 구조를 정의합니다. 이를 통해 뷰 행렬(`u_viewMatrix`), 해상도(`u_resolution`) 등 외부에서 제어해야 하는 값들을 타입 안전적으로 관리할 수 있습니다.
