# 🌱 Digital Garden

개발 과정에서 축적된 기술 문서와 학습 자료를 정리한 디지털 가든입니다.

## 📚 주요 카테고리

### 🎯 [Interaction & Scope Management](interaction/)
웹 애플리케이션의 이벤트 처리, 스코프 관리, 접근성 구현에 관한 문서입니다.
- IME 입력 보호 시스템
- 계층화된 오버레이 스코프
- 멀티 포인터 적응 시스템
- ARIA 접근성 구현

### 🎨 [WebGL Rendering](realtime-rendering/)
WebGL 렌더링 파이프라인과 실시간 그래픽스 구현에 대한 심층 가이드입니다.
- 렌더링 라이프사이클 마스터 맵
- GPU 파이프라인 단계별 상세 설명
- 성능 최적화 및 디버깅 기법

### 📐 [Coordinate Systems](coordinate_system/)
2D/3D 좌표 변환과 뷰포트 관리 시스템에 대한 문서입니다.
- 좌표계 변환 마스터 가이드
- 행렬 변환의 기초
- Canvas와 브라우저 통합

### ⚡ [WebGL Canvas Engine](WebGLCanvasEngine/)
고성능 WebGL 렌더링 엔진 구현에 관한 문서입니다.
- Ubershader 시스템 설계
- GLSL 셰이더 관리
- GPU 리소스 최적화

### 🗂️ [File Explorer Architecture](fileExplorer/)
파일 시스템 추상화와 상태 관리 아키텍처 문서입니다.
- FsProvider 유니버설 어댑터
- 상태 관리 패턴
- 동시성 처리와 에러 핸들링

### 💅 [Tailwind CSS Guide](tailwind/)
Tailwind CSS 활용과 최적화 가이드입니다.
- Utility-First 철학
- JIT 컴파일러 활용
- 프로덕션 최적화 전략

### 🤖 [Agentic Design Patterns](Agentic_Design_Patterns-main/)
AI 에이전트 설계 패턴과 구현 예제 모음입니다.
- 프롬프트 체이닝
- 멀티 에이전트 협업
- 메모리 관리 패턴

### 🧠 [Context Engineering](Context_Engineering/)
LLM 컨텍스트 최적화와 메모리 시스템 설계 문서입니다.
- 병렬 번역 메모리 시스템
- 컨텍스트 윈도우 관리

### 🔧 [Scope Management System](scope-management/)
프론트엔드 스코프 관리 시스템 리팩토링 프로젝트입니다.
- 시스템 아키텍처
- Redux 통합 전략
- 성능 최적화 벤치마크
