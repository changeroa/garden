# Zen

OpenCode에서 제공하는 큐레이션된 모델 목록.

OpenCode Zen은 OpenCode 팀이 테스트하고 검증한 모델 목록입니다.

> **Note**: OpenCode Zen은 현재 베타 버전입니다.

Zen은 OpenCode의 다른 제공자와 마찬가지로 작동합니다. OpenCode Zen에 로그인하고 API 키를 얻습니다. **완전히 선택 사항**이며 OpenCode를 사용하기 위해 반드시 사용할 필요는 없습니다.

---

## 배경

많은 모델이 있지만 코딩 에이전트로서 잘 작동하는 모델은 소수에 불과합니다. 또한 대부분의 제공자는 매우 다르게 구성되어 있어 성능과 품질이 매우 다릅니다.

> **Tip**: 코딩 에이전트에 가장 적합한 모델/제공자 그룹을 테스트했습니다.

OpenRouter와 같은 것을 통해 모델을 사용하는 경우 원하는 모델의 최상의 버전을 얻고 있는지 확신할 수 없습니다.

이를 해결하기 위해 몇 가지 작업을 수행했습니다:

1. 선택된 모델 그룹을 테스트하고 최적의 실행 방법에 대해 팀과 논의했습니다.
2. 그런 다음 이들이 올바르게 제공되도록 몇몇 제공자와 협력했습니다.
3. 마지막으로 모델/제공자 조합을 벤치마킹하고 권장할 수 있는 목록을 만들었습니다.

OpenCode Zen은 이러한 모델에 대한 액세스를 제공하는 AI 게이트웨이입니다.

---

## 작동 방식

OpenCode Zen은 OpenCode의 다른 제공자와 마찬가지로 작동합니다.

1. **[OpenCode Zen](https://opencode.ai/auth)**에 로그인하고 결제 정보를 추가한 다음 API 키를 복사합니다.
2. TUI에서 `/connect` 명령을 실행하고 OpenCode Zen을 선택한 다음 API 키를 붙여넣습니다.
3. TUI에서 `/models`를 실행하여 권장 모델 목록을 확인합니다.

요청당 요금이 부과되며 계정에 크레딧을 추가할 수 있습니다.

## 개인정보

모든 모델은 미국에서 호스팅됩니다. 제공자는 제로 보존 정책을 따르며 다음 예외를 제외하고 모델 훈련에 데이터를 사용하지 않습니다:

- Grok Code Fast 1: 무료 기간 동안 수집된 데이터는 Grok Code 개선에 사용될 수 있습니다.
- GLM 4.7: 무료 기간 동안 수집된 데이터는 모델 개선에 사용될 수 있습니다.
- MiniMax M2.1: 무료 기간 동안 수집된 데이터는 모델 개선에 사용될 수 있습니다.
- OpenAI API: [OpenAI의 데이터 정책](https://platform.openai.com/docs/guides/your-data)에 따라 요청이 30일 동안 보존됩니다.
- Anthropic API: [Anthropic의 데이터 정책](https://docs.anthropic.com/en/docs/claude-code/data-usage)에 따라 요청이 30일 동안 보존됩니다.

## 팀용

Zen은 팀에서도 잘 작동합니다. 팀원을 초대하고, 역할을 할당하고, 팀이 사용하는 모델을 큐레이션할 수 있습니다.

> **Note**: 워크스페이스는 현재 베타의 일부로 팀에게 무료입니다.

### 역할

팀원을 워크스페이스에 초대하고 역할을 할당할 수 있습니다:

- **Admin**: 모델, 구성원, API 키 및 결제 관리
- **Member**: 자신의 API 키만 관리

관리자는 비용을 통제하기 위해 각 구성원에 대한 월별 지출 한도를 설정할 수도 있습니다.

### 모델 액세스

관리자는 워크스페이스에 대한 특정 모델을 활성화하거나 비활성화할 수 있습니다. 비활성화된 모델에 대한 요청은 오류를 반환합니다.

데이터를 수집하는 모델의 사용을 비활성화하려는 경우에 유용합니다.
