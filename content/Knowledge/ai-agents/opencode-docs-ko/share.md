# 공유

OpenCode 대화 공유하기.

OpenCode의 공유 기능을 사용하면 OpenCode 대화에 대한 공개 링크를 만들어 팀원과 협업하거나 다른 사람의 도움을 받을 수 있습니다.

> **Note**: 공유된 대화는 링크가 있는 모든 사람이 공개적으로 액세스할 수 있습니다.

---

## 작동 방식

대화를 공유하면 OpenCode는:

1. 세션에 대한 고유한 공개 URL을 만듭니다
2. 대화 기록을 서버에 동기화합니다
3. 공유 가능한 링크 `opncd.ai/s/<share-id>`를 통해 대화에 액세스할 수 있게 만듭니다

---

## 공유

OpenCode는 대화 공유 방법을 제어하는 세 가지 공유 모드를 지원합니다:

### 수동 (기본값)

기본적으로 OpenCode는 수동 공유 모드를 사용합니다. 세션은 자동으로 공유되지 않지만 `/share` 명령을 사용하여 수동으로 공유할 수 있습니다:

```
/share
```

이렇게 하면 클립보드에 복사될 고유 URL이 생성됩니다.

[설정 파일](/docs/config)에서 수동 모드를 명시적으로 설정하려면:

```json
{
  "$schema": "https://opncd.ai/config.json",
  "share": "manual"
}
```

### 자동 공유

[설정 파일](/docs/config)에서 `share` 옵션을 `"auto"`로 설정하여 모든 새 대화에 대해 자동 공유를 활성화할 수 있습니다:

```json
{
  "$schema": "https://opncd.ai/config.json",
  "share": "auto"
}
```

자동 공유가 활성화되면 모든 새 대화가 자동으로 공유되고 링크가 생성됩니다.

### 비활성화

[설정 파일](/docs/config)에서 `share` 옵션을 `"disabled"`로 설정하여 공유를 완전히 비활성화할 수 있습니다:

```json
{
  "$schema": "https://opncd.ai/config.json",
  "share": "disabled"
}
```

특정 프로젝트에 대해 팀 전체에서 이를 적용하려면 프로젝트의 `opencode.json`에 추가하고 Git에 체크인합니다.

---

## 공유 해제

대화 공유를 중지하고 공개 액세스에서 제거하려면:

```
/unshare
```

이렇게 하면 공유 링크가 제거되고 대화와 관련된 데이터가 삭제됩니다.

---

## 개인정보

대화를 공유할 때 몇 가지 유의해야 할 사항이 있습니다.

### 데이터 보존

공유된 대화는 명시적으로 공유 해제할 때까지 액세스할 수 있습니다. 여기에는 다음이 포함됩니다:

- 전체 대화 기록
- 모든 메시지 및 응답
- 세션 메타데이터

### 권장 사항

- 민감한 정보가 포함되지 않은 대화만 공유하세요.
- 공유하기 전에 대화 내용을 검토하세요.
- 협업이 완료되면 대화 공유를 해제하세요.
- 독점 코드나 기밀 데이터가 있는 대화는 공유하지 마세요.
- 민감한 프로젝트의 경우 공유를 완전히 비활성화하세요.

---

## 기업용

기업 배포의 경우 공유 기능은:

- 보안 규정 준수를 위해 완전히 **비활성화**
- SSO를 통해 인증된 사용자로만 **제한**
- 자체 인프라에 **자체 호스팅**

조직에서 opencode를 사용하는 방법에 대해 [자세히 알아보기](/docs/enterprise).
