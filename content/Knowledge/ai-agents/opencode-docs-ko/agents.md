# 에이전트

전문 에이전트 구성 및 사용.

에이전트는 특정 작업과 워크플로에 맞게 구성할 수 있는 전문 AI 어시스턴트입니다. 사용자 정의 프롬프트, 모델 및 도구 액세스로 집중된 도구를 만들 수 있습니다.

> **Tip**: plan 에이전트를 사용하여 코드 변경 없이 코드를 분석하고 제안을 검토하세요.

세션 중에 에이전트를 전환하거나 `@` 멘션으로 호출할 수 있습니다.

---

## 유형

OpenCode에는 두 가지 유형의 에이전트가 있습니다: 기본 에이전트와 서브 에이전트.

### 기본 에이전트

기본 에이전트는 직접 상호 작용하는 주요 어시스턴트입니다. **Tab** 키를 사용하여 순환하거나 구성된 `switch_agent` 키바인드를 사용할 수 있습니다. 이러한 에이전트는 주요 대화를 처리하고 구성된 모든 도구에 액세스할 수 있습니다.

> **Tip**: 세션 중에 **Tab** 키를 사용하여 기본 에이전트 간에 전환할 수 있습니다.

OpenCode에는 두 개의 내장 기본 에이전트인 **Build**와 **Plan**이 함께 제공됩니다.

### 서브 에이전트

서브 에이전트는 기본 에이전트가 특정 작업을 위해 호출할 수 있는 전문 어시스턴트입니다. 메시지에서 **@ 멘션**으로 수동으로 호출할 수도 있습니다.

OpenCode에는 두 개의 내장 서브 에이전트인 **General**과 **Explore**가 함께 제공됩니다.

---

## 내장

### Build

*모드*: `primary`

모든 도구가 활성화된 **기본** 기본 에이전트입니다. 파일 작업 및 시스템 명령에 대한 전체 액세스가 필요한 개발 작업을 위한 표준 에이전트입니다.

### Plan

*모드*: `primary`

계획 및 분석을 위해 설계된 제한된 에이전트입니다. 권한 시스템을 사용하여 더 많은 제어를 제공하고 의도하지 않은 변경을 방지합니다. 기본적으로 다음은 모두 `ask`로 설정됩니다:

- `file edits`: 모든 쓰기, 패치 및 편집
- `bash`: 모든 bash 명령

이 에이전트는 LLM이 코드베이스를 실제로 수정하지 않고 코드를 분석하고, 변경 사항을 제안하거나, 계획을 만들도록 하려는 경우에 유용합니다.

### General

*모드*: `subagent`

복잡한 질문을 연구하고, 코드를 검색하고, 다단계 작업을 실행하기 위한 범용 에이전트입니다. 키워드나 파일을 검색할 때 처음 몇 번의 시도에서 올바른 일치를 찾을 수 있을지 확신이 없을 때 사용합니다.

### Explore

*모드*: `subagent`

코드베이스 탐색에 특화된 빠른 에이전트입니다. 패턴으로 파일을 빠르게 찾거나, 키워드로 코드를 검색하거나, 코드베이스에 대한 질문에 답해야 할 때 사용합니다.

---

## 사용법

1. 기본 에이전트의 경우 세션 중에 **Tab** 키를 사용하여 순환합니다. 구성된 `switch_agent` 키바인드를 사용할 수도 있습니다.

2. 서브 에이전트는 다음과 같이 호출할 수 있습니다:
   - 기본 에이전트가 설명에 따라 전문 작업을 위해 **자동으로**.
   - 메시지에서 서브 에이전트를 **@ 멘션**하여 수동으로.

```
@general 이 함수를 검색하는 것을 도와주세요
```

3. **세션 간 탐색**: 서브 에이전트가 자체 자식 세션을 만들 때 다음을 사용하여 부모 세션과 모든 자식 세션 사이를 탐색할 수 있습니다:
   - **<Leader>+Right** - 앞으로 순환
   - **<Leader>+Left** - 뒤로 순환

## 설정

### JSON

`opencode.json` 설정 파일에서 에이전트를 구성합니다:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "agent": {
    "build": {
      "mode": "primary",
      "model": "anthropic/claude-sonnet-4-20250514",
      "tools": {
        "write": true,
        "edit": true,
        "bash": true
      }
    },
    "code-reviewer": {
      "description": "모범 사례 및 잠재적 문제에 대한 코드 검토",
      "mode": "subagent",
      "model": "anthropic/claude-sonnet-4-20250514",
      "prompt": "당신은 코드 리뷰어입니다. 보안, 성능 및 유지 관리에 중점을 두세요.",
      "tools": {
        "write": false,
        "edit": false
      }
    }
  }
}
```

### Markdown

마크다운 파일을 사용하여 에이전트를 정의할 수도 있습니다. 다음 위치에 배치합니다:

- 전역: `~/.config/opencode/agent/`
- 프로젝트별: `.opencode/agent/`

```markdown
---
description: 품질 및 모범 사례에 대한 코드 검토
mode: subagent
model: anthropic/claude-sonnet-4-20250514
temperature: 0.1
tools:
  write: false
  edit: false
  bash: false
---

당신은 코드 검토 모드입니다. 다음에 중점을 두세요:

- 코드 품질 및 모범 사례
- 잠재적인 버그 및 엣지 케이스
- 성능 영향
- 보안 고려 사항

직접 변경하지 않고 건설적인 피드백을 제공하세요.
```

마크다운 파일 이름이 에이전트 이름이 됩니다. 예를 들어, `review.md`는 `review` 에이전트를 만듭니다.

## 옵션

### description

`description` 옵션을 사용하여 에이전트가 수행하는 작업과 사용 시기에 대한 간략한 설명을 제공합니다. 이것은 **필수** 설정 옵션입니다.

### temperature

`temperature` 설정으로 LLM 응답의 무작위성과 창의성을 제어합니다. 낮은 값은 응답을 더 집중적이고 결정론적으로 만들고, 높은 값은 창의성과 변동성을 증가시킵니다.

- **0.0-0.2**: 코드 분석 및 계획에 이상적인 매우 집중적이고 결정론적인 응답
- **0.3-0.5**: 일반 개발 작업에 좋은 약간의 창의성이 있는 균형 잡힌 응답
- **0.6-1.0**: 브레인스토밍 및 탐색에 유용한 더 창의적이고 다양한 응답

### maxSteps

에이전트가 텍스트로만 응답하도록 강제되기 전에 수행할 수 있는 최대 에이전트 반복 횟수를 제어합니다.

### prompt

`prompt` 설정으로 이 에이전트에 대한 사용자 정의 시스템 프롬프트 파일을 지정합니다.

### model

`model` 설정을 사용하여 이 에이전트의 모델을 재정의합니다. 다른 작업에 최적화된 다른 모델을 사용하는 데 유용합니다.

> **Tip**: 모델을 지정하지 않으면 기본 에이전트는 [전역적으로 구성된 모델](/docs/config#models)을 사용하고, 서브 에이전트는 호출한 기본 에이전트의 모델을 사용합니다.

### tools

`tools` 설정으로 이 에이전트에서 사용 가능한 도구를 제어합니다.

### mode

`mode` 설정으로 에이전트의 모드를 제어합니다. `mode` 옵션은 `primary`, `subagent` 또는 `all`로 설정할 수 있습니다. `mode`가 지정되지 않은 경우 기본값은 `all`입니다.

## 에이전트 만들기

다음 명령을 사용하여 새 에이전트를 만들 수 있습니다:

```bash
opencode agent create
```

이 대화형 명령은:

1. 에이전트를 저장할 위치(전역 또는 프로젝트별)를 묻습니다.
2. 에이전트가 수행해야 할 작업에 대한 설명.
3. 적절한 시스템 프롬프트와 식별자를 생성합니다.
4. 에이전트가 액세스할 수 있는 도구를 선택할 수 있습니다.
5. 마지막으로 에이전트 설정이 있는 마크다운 파일을 만듭니다.
