## 1. 서비스 워크플로우 (Service Blueprint)

사용자의 계약 여정(Journey)에 따라 **[탐색] → [가계약] → [본계약]** 3단계로 나누어 방어 로직을 수행함.

### Phase 1. 매물 탐색 & 검증 (Pre-Visit)
> [!SUMMARY] 목표: 헛걸음 방지 및 1차 필터링
> 집을 보러 가기 전, 주소만으로 치명적인 하자를 걸러내는 단계.

#### 1.1 입력 데이터 (Input)
- **주소 (Address):** 도로명/지번 주소 (사용자 입력)
- **보증금 (Deposit):** 전세/월세 보증금 액수

#### 1.2 에이전트 동작 (Agent Logic)
1.  **Data Fetching (공공 데이터 연동)**
    - `API_Call`: **인터넷 등기소** → [등기부등본] 열람 (소유자, 근저당 채권최고액)
    - `API_Call`: **정부24** → [건축물대장] 열람 (용도, 위반건축물 등재 여부)
    - `API_Call`: **KB부동산/국토부** → [실거래가] 조회 (매매 시세 추정)

2.  **Risk Calculation (위험도 연산)**
    - **깡통전세율 계산:** $\frac{\text{선순위 대출금} + \text{보증금}}{\text{주택 추정 시세}} \times 100$
    - **용도 적합성 검사:** `건축물 용도`가 '주택'인지 확인 (근린생활시설, 고시원 등 필터링)

#### 1.3 출력 (Output)
> [!example] 신호등 시스템
> - 🟢 **안전 (Safe):** 깡통전세율 70% 미만 + 주택 용도 적합 + 위반 사항 없음
> - 🟡 **주의 (Caution):** 깡통전세율 70~80% 구간 or 시세 불명확
> - 🔴 **위험 (Danger):** **근린생활시설(대출불가)** or 깡통전세율 80% 초과 or **경매 진행 중**

### Phase 2. 가계약 방어 (Pre-Deposit)
> [!DANGER] 핵심 승부처 (Critical Point)
> 가장 많은 피해가 발생하는 구간. 문자(카톡)만 믿고 돈을 보냈다가 돌려받지 못하는 상황을 방어.

#### 2.1 입력 데이터 (Input)
- **텍스트 (Text):** 중개사로부터 받은 계좌번호, 계약 조건이 담긴 문자/카톡 메시지 전체 복사

#### 2.2 에이전트 동작 (Agent Logic)
1.  **NLP Text Extraction (정보 추출)**
    - `Regex`: 계좌번호, 금액, 날짜, 동/호수 추출
    - `Named Entity Recognition`: 예금주 이름, 중개사 이름 식별
2.  **Cross Validation (교차 검증)**
    - **예금주 일치 확인:** Phase 1에서 확보한 [등기부상 소유자] vs 문자 내 [예금주] 대조
    - **중개사 자격 확인:** [국가공간정보포털] API로 등록된 중개사인지 확인 (보조원 여부 판별)
3.  **Missing Clause Detection (누락 특약 감지)**
    - "가계약금 반환" 관련 키워드(`반환`, `환불`, `결렬`) 존재 여부 스캔

#### 2.3 액션 아이템 (Action Item)
> [!TIP] 사용자 행동 가이드
> **1. 예금주 불일치 시:** 🚫 "절대 입금 금지! 등기부상 주인인 'OOO' 명의 계좌를 요구하세요."
> **2. 반환 특약 누락 시:** 아래 문구를 복사해서 보내라고 지시.
> ```text
> [가계약금 반환 특약 요청]
> "본 계약 진행 중 임대인과 임차인의 합의가 이루어지지 않거나,
> 전세자금 대출이 승인되지 않을 경우,
> 지급한 가계약금은 조건 없이 즉시 전액 반환한다."
> ```

### Phase 3. 본 계약 정밀 분석 (Contract Day)
> [!Check] 최종 점검
> 현장에서 종이 계약서를 작성할 때, 가계약 내용과 달라진 점이 없는지 확인.

#### 3.1 입력 데이터 (Input)
- **이미지 (Image):** 종이 계약서 사진 (표준 임대차 계약서 양식)

#### 3.2 에이전트 동작 (Agent Logic)
1.  **OCR & Layout Parsing (STORM Parse 활용)**
    - 계약서 내 주요 필드(보증금, 임대인, 특약사항)를 마크다운으로 변환.
    - 특히 **수기(Handwritten)로 작성된 [특약사항]** 인식에 집중.
2.  **Real-time Delta Check (변동 사항 추적)**
    - **시간차 대출 확인:** 가계약(Phase 2) 이후 ~ 현재(Phase 3) 사이 등기부 변동 내역 재조회 (그 사이 대출 받았는지 확인).
    - **말 바꾸기 탐지:** 가계약 문자 내용 vs 종이 계약서 특약 내용 비교.
3.  **Toxic Clause Filtering (독소 조항 필터링)**
    - LLM을 활용하여 임차인에게 불리한 법률 용어 탐지.

#### 3.3 출력 (Output)
- **수정 제안 리포트:**
    - "제 5조 2항 [청소비 전가] 조항은 삭제를 요구하세요."
    - "제 7조 [1년 뒤 퇴거] 특약은 주택임대차보호법 위반으로 무효지만, 분쟁 예방을 위해 삭제가 좋습니다."

## 2. 리스크 맵 (Risk Map & Defense Logic)

사용자가 직면할 수 있는 4가지 카테고리의 위험 요소와 이에 대한 방어 로직 상세.

### ① [물건] 집 자체의 문제 (The Property)

| 위험 요인 | 상세 설명 | 방어 로직 (Detection) |
| :--- | :--- | :--- |
| **[[깡통전세]]** | 매매가 $\approx$ (대출금 + 보증금). 경매 시 보증금 회수 불가. | **Logic:** `(근저당 + 보증금) / KB시세 > 0.8` 이면 **Danger** 경고. |
| **[[불법건축물]]** | '주택'이 아닌 '근린생활시설(상가)'. 취사 시설 불법 설치. | **Logic:** 건축물대장 `용도` 컬럼 파싱. "제2종근린생활시설" 키워드 검출 시 **경고(대출불가)**. |
| **[[위반건축물]]** | 베란다 불법 확장, 옥탑방 등. 이행강제금 부과 대상. | **Logic:** 건축물대장 상단 `[위반건축물]` 표기 유무 OCR 확인. |
| **권리 침해** | 압류, 가압류, 가처분, 경매개시결정 등 소유권 분쟁 중. | **Logic:** 등기부등본 [갑구] 내 `가압류`, `압류`, `경매` 키워드 스크래핑. |

### ② [돈] 금전 및 권리 순위 (The Money)

| 위험 요인           | 상세 설명                            | 방어 로직 (Detection)                                           |
| :-------------- | :------------------------------- | :---------------------------------------------------------- |
| **[[선순위 근저당]]** | 나보다 배당 순위가 앞서는 은행 대출.            | **Logic:** 등기부등본 [을구] `채권최고액` 합산 후 보증금과 비교 리포트 제공.          |
| **시간차 공격**      | 전입신고 효력(익일 0시) 전, 집주인이 당일 대출 실행. | **Prompt:** 특약사항에 "잔금일 **익일**까지 제한물권 설정을 금지한다" 문구 부재 시 경고.  |
| **세금 체납**       | 집주인의 국세/지방세 체납(0순위)으로 공매 진행.     | **Action:** 앱 내에서 [국세/지방세 완납 증명서] 요청 체크리스트 활성화.             |
| **계좌 불일치**      | 대리인, 가족, 부동산 법인 명의로 입금 유도.       | **Logic:** `등기부 소유자명` != `입금 계좌 예금주` 일 경우 **BLOCK** 수준의 경고. |

### ③ [사람] 사기꾼 판별 (The Person)

| 위험 요인 | 상세 설명 | 방어 로직 (Detection) |
| :--- | :--- | :--- |
| **무자격 중개** | 중개보조원(실장)이 공인중개사 행세. 사고 시 책임 회피. | **API:** 국가공간정보포털 API 연동 → 담당자 이름 조회 → "보조원입니다" 안내. |
| **가짜 임대인** | 위조 신분증 또는 월세 세입자가 집주인 행세(이중계약). | **Action:** 신분증 진위 확인(ARS 1382) 방법 안내 및 등기부상 주민번호 앞자리 대조. |
| **대리 계약** | "남편이 바빠서 부인인 제가 왔어요" (위임장 없음). | **Checklist:** 대리인 계약 시 필수 서류(인감증명서, 위임장, 신분증) UI 체크리스트 제공. |

### ④ [계약] 독소 조항 및 법적 함정 (The Contract)

| 위험 요인 | 상세 설명 | 방어 로직 (Detection) |
| :--- | :--- | :--- |
| **가계약금 몰취** | 계약 미진행 시 가계약금을 돌려주지 않음. | **Prompt:** 텍스트 분석 시 "단순 변심 반환 불가" vs "조건부 반환" 문구 구분. |
| **대출 불가 먹튀** | 전세대출 거절되어도 계약금 안 돌려줌. | **Prompt:** "전세대출 미승인 시 **무효** 및 **반환**" 키워드 세트 확인. |
| **수리비 전가** | "퇴거 시 일체 수리비 부담" 등 포괄적 전가. | **Prompt:** "자연 마모(통상적 손모)" 배제 조항 탐지 시, 수정 문구 제안. |
| **[[계약갱신청구권]] 무력화** | "1년 뒤 조건 없이 퇴거한다" 특약. | **Law:** 주택임대차보호법 강행규정 위반임을 알리고, 효력 없음을 안내. |

## 3. 기술 스택 (Tech Stack for Hackathon)
- **Input Processing:** `STORM Parse` (PDF/Image to Markdown)
- **Logic Engine:** `Python` (Validation Logic, Calculator)
- **Intelligence:** `OpenAI GPT-4o` (Risk Analysis, Clause Generation)
- **External Data:** `Government API` (Mock-up or Real-time Scraping)
