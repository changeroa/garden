상주 운영체제(Resident Operating System)란 컴퓨터가 켜져 있는 동안 **항상 메인 메모리(RAM)에 머물러 있는 운영체제의 부분**을 말합니다.

- 운영체제의 핵심 (커널) 운영체제 프로그램 전체가 메모리에 다 올라와 있으면 메모리 공간을 너무 많이 차지합니다. 그래서 운영체제 중 가장 중요하고 빈번하게 사용되는 핵심 부분만 메모리에 계속 올려두는데, 이를 상주 운영체제 또는 커널(Kernel)이라고 부릅니다.
    
- 왜 상주해야 하나요? 인터럽트 처리, 프로세스 스케줄링, 메모리 할당 같은 작업은 시스템이 돌아가는 내내 쉴 새 없이 발생합니다. 이 기능들은 언제 요청이 올지 모르기 때문에 디스크에 두지 않고, 즉시 실행 가능한 상태로 메모리에 계속 둬야 합니다.
    
- 교재 내용과의 연결 방금 보신 내용에서 "Low memory with interrupt vector"라고 나왔죠? 인터럽트 벡터(하드웨어 신호를 처리하는 주소 목록)가 보통 메모리의 가장 낮은 주소(0번지 부근)에 위치합니다. 그래서 이와 밀접하게 일해야 하는 상주 운영체제도 보통 하위 메모리(Low memory)에 배치됩니다.
    
- 비상주 영역 반대로 자주 쓰지 않는 운영체제의 기능(예: 도움말 프로그램, 일부 설정 도구 등)은 평소엔 하드디스크에 있다가 필요할 때만 메모리로 불러옵니다.
