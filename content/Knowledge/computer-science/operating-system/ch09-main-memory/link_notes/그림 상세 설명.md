**일반적인 4-KB 페이지 경로 (위쪽 경로)**

1. **CR3 레지스터:** 현재 프로세스의 **Page Directory(페이지 디렉터리)**가 어디 있는지 가리킵니다.
    
2. **Directory Lookup (상위 10비트):**
    
    - 선형 주소의 앞쪽 `10비트(p1)`를 보고 디렉터리의 몇 번째 칸으로 갈지 정합니다.
        
    - 그 칸에는 **Page Table(페이지 테이블)**의 위치가 적혀 있습니다.
        
3. **Table Lookup (중간 10비트):**
    
    - 페이지 테이블로 가서, 선형 주소의 중간 `10비트(p2)`를 보고 몇 번째 칸으로 갈지 정합니다.
        
    - 그 칸에는 실제 메모리의 **4-KB Page(프레임)** 위치가 적혀 있습니다.
        
4. **Offset (하위 12비트):**
    
    - 마지막 `12비트(offset)`를 사용해 프레임 내에서의 정확한 위치를 찾아갑니다.
        

**특수 케이스: 4-MB 페이지 경로 (아래쪽 경로)**

- 그림 아래쪽에 `4-MB page`라는 큰 박스가 보이죠?
    
- 만약 페이지 크기를 4MB로 설정했다면, **페이지 테이블 조회 단계(중간 단계)를 생략**합니다.
    
- 페이지 디렉터리가 바로 거대한 4MB짜리 물리 페이지를 가리키게 되며, 이때는 하위 22비트를 전부 오프셋으로 사용합니다.
