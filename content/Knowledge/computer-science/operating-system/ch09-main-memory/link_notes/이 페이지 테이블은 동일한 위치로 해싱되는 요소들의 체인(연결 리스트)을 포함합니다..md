### 1. 기본 개념

전통적인 페이지 테이블은 모든 가능한 가상 주소에 대한 항목을 가지고 있어 크기가 매우 커질 수 있습니다. 반면, 해시 페이지 테이블은 **"실제로 사용 중인 페이지"**의 정보만을 해시 테이블에 저장하여 메모리 공간을 절약합니다.

### 2. 동작 원리 및 구조

- **해시 함수:** **가상 페이지 번호(Virtual Page Number)**를 입력으로 받아 해시 값을 생성합니다. 이 해시 값은 해시 테이블의 인덱스(버킷)를 가리킵니다.
    
- **체이닝(Chaining):** 해시 함수의 특성상 서로 다른 가상 페이지 번호가 같은 해시 값을 가질 수 있습니다(해시 충돌). 이를 해결하기 위해 각 해시 버킷은 **동일한 위치로 해싱되는 요소들의 연결 리스트(Chain)**를 가리킵니다.
    
- **요소의 구성:** 연결 리스트의 각 요소는 다음 세 가지 정보를 포함합니다.
    
    1. **가상 페이지 번호 (Virtual Page Number):** 실제 찾고자 하는 페이지 번호인지 확인하기 위해 필요합니다.
        
    2. **매핑된 페이지 프레임 번호 (Mapped Page Frame):** 해당 가상 페이지가 실제 물리 메모리의 어디에 있는지 알려주는 값입니다.
        
    3. **다음 요소를 가리키는 포인터 (Pointer to the next element):** 연결 리스트를 탐색하기 위해 사용됩니다.
