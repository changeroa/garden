$$A = B + \left( (A + F(B, C, D) + M_i + K_i) \lll s \right)$$

#### 변수 설명

- **$A, B, C, D$**: 현재 MD Buffer의 상태값 (각 32비트).
    
- **$F$**: 비선형 함수 (라운드마다 달라짐).
    
- **$M_i$**: 현재 처리 중인 메시지 조각 (32비트).
    
- **$K_i$**: 미리 정해진 상수값 (32비트).
    
- **$\lll s$**: 왼쪽으로 비트 회전 (Left Circular Shift).
    
- **$+$**: 덧셈 (Mod $2^{32}$, 넘치는 건 버림).


### 세부 연산 단계별 설명

위 공식을 컴퓨터가 처리하는 순서대로 쪼개면 다음과 같습니다. (변수 $A$를 갱신하는 상황을 가정)

#### ① 비선형 함수 계산 (Non-linear Function)

가장 먼저, $A$를 제외한 나머지 세 변수($B, C, D$)를 **비선형 함수**에 넣습니다.

> **의미**: "현재 상태값들을 섞어서 예측 불가능한 값을 만들어라."

라운드별로 사용하는 함수가 다릅니다:

- **Round 1 ($F$)**: $(B \land C) \lor (\neg B \land D)$
    
    - _설명_: $B$가 1이면 $C$를 선택, 0이면 $D$를 선택. (조건부 선택)
        
- **Round 2 ($G$)**: $(B \land D) \lor (C \land \neg D)$
    
    - _설명_: $F$와 비슷하지만 $D$를 기준으로 선택.
        
- **Round 3 ($H$)**: $B \oplus C \oplus D$
    
    - _설명_: 셋 다 **XOR** 함. 비트의 차이를 극대화.
        
- **Round 4 ($I$)**: $C \oplus (B \lor \neg D)$
    
    - _설명_: 가장 복잡한 연산. 패턴을 완전히 파괴함.
        

#### ② 1차 덧셈 (Addition)

위에서 나온 결과값에 현재의 **$A$** 값을 더합니다.

> **식**: `Result = Result + A`

#### ③ 메시지 합치기 (Add Message Chunk)

여기에 **메시지 조각($M_i$)**을 더합니다. 512비트 블록을 32비트씩 쪼갠 16개 중 하나입니다.

> 식: Result = Result + M[i]
> 
> 의미: 우리의 실제 데이터를 암호화 과정에 투입하는 단계입니다.

#### ④ 상수 합치기 (Add Constant)

여기에 **상수($K_i$)**를 더합니다.

> 식: Result = Result + K[i]
> 
> 의미: $K_i$는 sin(i) 값을 이용해 만든 난수표입니다. 입력 데이터가 0000... 처럼 단순해도 결과가 복잡해지도록 '소금'을 치는 과정입니다.

#### ⑤ 비트 회전 (Left Circular Shift) ⭐

지금까지 더해진 값(`Result`)을 왼쪽으로 $s$비트만큼 **빙글 돌립니다.**

> 식: Result = Result <<< s
> 
> 동작: 1011...을 왼쪽으로 1칸 밀면 011...1이 됨 (맨 앞 비트가 맨 뒤로 이동).
> 
> 의미: 비트들의 자릿수를 바꿔서, 다음번 덧셈 때 전혀 다른 자릿수에 영향을 주도록 만듭니다. (확산 효과)

#### ⑥ 2차 덧셈 (Add B)

마지막으로, 현재의 **$B$** 값을 더합니다.

> 식: Result = Result + B
> 
> 의미: 이전 단계의 결과와 연결고리를 만들어(Chaining), 앞 단계의 변화가 뒤에 계속 영향을 미치게 합니다.

#### ⑦ 결과 저장

이 최종 결과(`Result`)를 **새로운 $A$**로 덮어씁니다.
