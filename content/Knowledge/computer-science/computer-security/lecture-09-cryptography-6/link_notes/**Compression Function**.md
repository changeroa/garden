> # 그럼 compression function은 뭐야?
> Compression Function은 Merkle-Damgård Scheme에서 핵심적인 역할을 하는 함수입니다. 입력 문자열을 블록으로 나누고 패딩을 적용한 후, 각 블록을 이전 결과와 함께 혼합(mixing)하여 다음 단계의 입력으로 사용하는 역할을 합니다. 간단하게는 비트 단위 XOR이나 순환 시프트(rotation)를 사용할 수 있지만, 실제 암호화 알고리즘에서는 훨씬 복잡한 연산을 사용합니다. 초기 벡터(IV)와 함께 블록들을 순차적으로 처리하면서 해시 값을 생성하는 과정에서 중요한 부분입니다.
