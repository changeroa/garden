> ### ICMP (Internet Control Message Protocol)
> **핵심 정의:**
> ICMP는 인터넷에서 오류 메시지나 상태 정보를 전달하기 위한 프로토콜입니다. 쉽게 말해, 네트워크 장비들이 서로에게 "어떻게 되고 있는지" 혹은 "문제가 발생했어요!"라는 메시지를 보내는 방법입니다.
> **예시 및 배경지식:**
> 예를 들어, 컴퓨터가 다른 컴퓨터에 데이터를 보내려 할 때, 네트워크에 문제가 생기면 ICMP는 "이 서버에 도달할 수 없어요!"라는 오류 메시지를 보냅니다. 이를 통해 사용자나 관리자가 문제를 파악하고 해결할 수 있게 됩니다.
