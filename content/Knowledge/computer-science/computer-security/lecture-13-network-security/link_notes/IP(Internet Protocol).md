> ### 개념: IP(Internet Protocol)
> #### 설명:
> - **정의**: IP는 인터넷에서 데이터 패킷을 전송하기 위한 규칙과 형식을 정의하는 프로토콜입니다.
> - **비연결형**: IP는 "비연결형 프로토콜"로, 데이터 전송 전에 연결을 설정할 필요가 없음을 의미합니다. 즉, 송신자와 수신자 간의 지속적인 연결을 유지하지 않고 각 패킷이 독립적으로 전송됩니다.
> - **데이터 전송 방식**: 각 패킷은 독립적으로 라우팅되며, 목적지에 도달하는 경로가 다를 수 있습니다. 이 때문에 패킷의 순서가 바뀌거나 일부 패킷이 손실될 수 있습니다.
> - **기능**: IP는 주소 지정 및 라우팅 기능을 제공하여, 데이터를 올바른 위치로 전달할 수 있도록 합니다. 각 장치는 고유한 IP 주소를 통해 식별됩니다.
> 이러한 특성으로 인해, IP는 인터넷 상에서 다양한 데이터 통신의 기본이 되는 중요한 프로토콜입니다.
