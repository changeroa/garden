- **관련:** [[프로덕션 최적화]], [[PurgeCSS]]

## 📝 핵심 정리
개발 과정에서 사용되는 모든 클래스를 실시간으로 감지하여, 필요한 CSS만 즉시 생성하는 고성능 컴파일 엔진입니다. 이로 인해 개발 중에도 최종 빌드와 거의 동일한 성능을 경험할 수 있습니다.

## 💻 코드 예제 (JIT 컴파일러의 동적 생성)

/**
 * ==========================================
 * [기능명]: JIT의 동적 클래스 생성
 * ==========================================
 *
 * 📖 목적: JIT 컴파일러가 어떻게 임의의 값으로도 유틸리티 클래스를 생성하는지 보여줍니다.
 * 🏗️ 구조: `tailwind.config.js`에 미리 정의되지 않은 `top-[117px]` 같은 임의의 값을 HTML에 직접 사용합니다.
 * 🔄 흐름: 개발 서버가 실행 중일 때, JIT 엔진은 파일의 변경사항을 감지하고 `top-[117px]`에 해당하는 CSS(`top: 117px;`)를 즉시 생성하여 브라우저에 주입합니다.
 * 🎯 학습포인트: JIT 덕분에 디자인 시스템에 없는 특정 값을 써야 할 때도 HTML을 벗어날 필요가 없다는 점을 이해합니다.
 */

```html
<!-- 이 코드를 HTML에 추가하면 JIT가 즉시 아래 CSS를 생성합니다 -->
<div class="top-[117px] bg-[#bada55]">
  이 요소는 JIT에 의해 동적으로 스타일링됩니다.
</div>
```

```css
/* JIT에 의해 생성된 CSS (실제 파일에 저장되지 않음) */
.top-\[117px\] {
  top: 117px;
}
.bg-\[\#bada55\] {
  --tw-bg-opacity: 1;
  background-color: rgb(186 218 85 / var(--tw-bg-opacity));
}
```

## 🔍 상세 분석

### 문법 포인트
- **Arbitrary Values (임의 값)**: `w-[32rem]`, `p-[13px]`, `text-[#ff0000]` 처럼 대괄호(`[]`)를 사용하여 설정 파일에 없는 값을 직접 사용할 수 있습니다.
- **Variant Stacking (변형 중첩)**: `dark:md:hover:text-red-500` 처럼 다크 모드, 특정 화면 크기, 마우스 호버 상태를 모두 조합하여 매우 구체적인 조건의 스타일을 만들 수 있습니다.

### 로직 포인트
- **초고속 스캔**: 초기 빌드 후, 파일의 변경된 부분만 스캔하므로 거의 즉각적으로 스타일이 반영됩니다.
- **모든 변형 기본 활성화**: `group-hover`, `focus-visible` 등 모든 변형(variant)이 기본적으로 활성화되어 있어 별도의 설정 없이 바로 사용할 수 있습니다.

### 실무 포인트
- **개발 경험 향상**: 거대한 CSS 파일을 미리 빌드할 필요가 없어 개발 서버 시작 시간이 매우 빠릅니다.
- **디자인 일관성 유지**: 임의 값을 사용할 수는 있지만, 팀의 디자인 시스템을 따르기 위해 `tailwind.config.js`에 정의된 값을 우선적으로 사용하는 것이 권장됩니다.
