# KnowledgeOS Vault

이 리포지토리는 개인 지식 관리와 인피니트 캔버스 기반 사고 확장을 위한 Obsidian Vault입니다.

## 구조

```text
KnowledgeOS/
 ├─ 00_Inbox/          # 빠른 메모 / 임시 노트
 ├─ 01_Knowledge/      # 정제된 지식, 개념, 이론
 ├─ 02_Projects/       # 프로젝트 단위 기록
 ├─ 03_Canvas/         # Obsidian Canvas(.canvas) 파일
 ├─ 04_Archive/        # 완료된 프로젝트 및 구 노트
 ├─ Attachments/       # 이미지 / 파일 첨부
 ├─ Templates/         # 노트/프로젝트 템플릿
 ├─ System/            # 인덱스, Dataview 쿼리, 메타 노트
 └─ .obsidian/         # Obsidian 설정 (일부 파일은 .gitignore로 제외)
