## 📝 핵심 정리
월드에서 스크린으로 가는 변환(`viewMatrix`)이 있을 때, 그 반대 방향인 스크린에서 월드로 가는 변환을 수행하는 `inverseViewMatrix`를 계산합니다.

## 💻 코드 예제 (완전 주석)

```typescript
/**
 * ==========================================
 * [기능명]: 역행렬 계산
 * ==========================================
 * 
 * 📖 목적: viewMatrix의 변환을 거꾸로 수행하는 행렬을 계산합니다.
 * 🏗️ 구조: 원본 행렬의 크기(Scale)와 이동(Translate) 값의 역수를 취하여 역행렬을 만듭니다.
 * 🔄 흐름: updateMatrices() 내부에서 viewMatrix가 계산된 직후 호출됩니다.
 * 🎯 학습포인트: 역행렬의 개념과, 이동/크기만 있는 단순한 행렬의 역행렬을 구하는 방법을 배웁니다.
 */
private calculateInverseMatrix(): void {
  const m = this.viewMatrix; // 원본 변환 행렬 (월드 -> 스크린)

  // 1. 역 스케일 계산
  // 원본 스케일의 역수를 취합니다. (예: 2배 확대의 역변환은 1/2배 축소)
  const invScaleX = 1 / m[0]; // 1 / scaleX
  const invScaleY = 1 / m[4]; // 1 / scaleY

  // 2. 역 이동 계산
  // 원본 이동 값에 역 스케일을 곱하고 부호를 반전합니다.
  const invTx = -m[6] * invScaleX;
  const invTy = -m[7] * invScaleY;

  // 3. inverseViewMatrix에 값 할당
  const invM = this.inverseViewMatrix;
  invM[0] = invScaleX;
  invM[1] = 0;
  invM[2] = 0;
  invM[3] = 0;
  invM[4] = invScaleY;
  invM[5] = 0;
  invM[6] = invTx;
  invM[7] = invTy;
  invM[8] = 1;
}
```

## 🔍 상세 분석

### 로직 포인트
-   이 함수가 동작하는 원리는 변환의 순서를 거꾸로 적용하는 것입니다.
-   원래 변환: `new_pos = (old_pos * scale) + translate`
-   역변환: `old_pos = (new_pos - translate) / scale = new_pos * (1/scale) - translate * (1/scale)`
-   여기서 `1/scale`이 `invScaleX`, `invScaleY`에 해당하고, `-translate * (1/scale)` 부분이 `invTx`, `invTy`에 해당합니다.
-   이 코드는 회전이나 기울임이 없는(orthographic) 행렬에만 적용할 수 있는 간단한 역행렬 계산법입니다. 만약 회전이 포함된다면 훨씬 복잡한 계산이 필요합니다.

### 실무 포인트
-   역행렬은 `screenToWorld` 변환, 즉 화면의 마우스 클릭 위치에 어떤 월드 객체가 있는지 찾아내는 '히트 테스팅(hit testing)'에 필수적입니다.
-   매번 역행렬을 계산하는 것은 비용이 크므로, `viewMatrix`가 업데이트될 때 한 번만 계산해두고 캐싱하여 사용하는 것이 효율적입니다.
