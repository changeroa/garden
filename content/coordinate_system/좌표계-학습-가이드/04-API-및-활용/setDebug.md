# setDebug

## 🔗 연결
-   **상위:** `[[03-변환-엔진/CoordinateTransform 클래스]]`
-   **관련:** `[[03-변환-엔진/생성자 및 초기화]]`

## 📝 핵심 정리
클래스의 디버그 모드를 켜거나 끕니다.

## 💻 코드 예제 (완전 주석)

```typescript
/**
 * ==========================================
 * [기능명]: 디버그 모드 설정
 * ==========================================
 * 
 * 📖 목적: 개발 중에만 필요한 디버깅 정보(로그, 시각적 표시 등)를 제어하기 위해 사용됩니다.
 * 🏗️ 구조: boolean 값을 받아 내부 `debug` 플래그를 설정합니다.
 * 🎯 학습포인트: 디버깅용 코드와 실제 프로덕션 코드를 분리하는 간단한 방법을 배웁니다.
 */
public setDebug(enabled: boolean): void {
  this.debug = enabled;
}
```

## 🔍 상세 분석

### 로직 포인트
-   이 함수는 내부의 `debug` 플래그 값을 변경하는 단순한 setter 메서드입니다.
-   클래스의 다른 메서드 내부에서는 `if (this.debug) { ... }` 와 같은 조건문을 사용하여, 디버그 모드가 켜져 있을 때만 특정 코드가 실행되도록 할 수 있습니다.

### 실무 포인트
-   **디버깅 정보 시각화**: `debug` 모드가 켜져 있을 때, 캔버스 위에 현재 `viewport` 정보(중심 좌표, 줌 레벨)를 텍스트로 그리거나, 월드 좌표계의 원점(0,0)이나 그리드를 표시해주는 기능을 추가할 수 있습니다. 이는 좌표 변환이 올바르게 작동하는지 시각적으로 확인하는 데 큰 도움이 됩니다.
-   **성능 저하 방지**: 디버깅을 위한 코드는 종종 성능을 저하시킬 수 있습니다. `debug` 플래그를 사용하여 프로덕션 빌드에서는 이러한 코드들이 실행되지 않도록 하여 성능 저하를 방지할 수 있습니다.
-   개발자 도구의 콘솔에서 `app.transform.setDebug(true)` 와 같은 명령어를 실행하여 실시간으로 디버그 모드를 켜고 끄는 기능을 만들면 매우 편리합니다.
