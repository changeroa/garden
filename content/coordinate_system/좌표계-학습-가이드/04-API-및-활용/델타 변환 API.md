## 📖 개념 설명
좌표의 절대 위치가 아닌, '변화량' 또는 '거리'를 다른 좌표계의 변화량으로 변환하는 API입니다. 예를 들어, 마우스를 화면에서 10px 드래그했을 때, 월드 공간에서는 얼마만큼 이동한 것인지를 계산하는 데 사용됩니다.

## 🗺️ 하위 구성요소
-   `screenDeltaToWorld`: 스크린에서의 픽셀 변화량을 월드 공간에서의 단위 변화량으로 변환합니다.
-   `worldDeltaToScreen`: 월드 공간에서의 단위 변화량을 스크린에서의 픽셀 변화량으로 변환합니다.

## 💡 실무 연결점
-   **패닝(Panning)**: 마우스를 드래그하여 지도를 움직일 때, 마우스의 픽셀 이동량(`deltaX`, `deltaY`)을 `screenDeltaToWorld`로 변환하여 `viewport.center`를 업데이트합니다.
-   **크기 조절 핸들**: 객체의 크기를 조절하는 핸들을 월드 단위로 10만큼 움직이고 싶을 때, `worldDeltaToScreen`을 사용하여 화면에 몇 픽셀을 그려야 하는지 계산할 수 있습니다.
