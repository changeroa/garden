## 📝 핵심 정리
2D 공간에서의 한 점을 나타내는 가장 기본적인 데이터 구조입니다.

## 💻 코드 예제 (완전 주석)

```typescript
/**
 * ==========================================
 * [기능명]: 2D 좌표 점 (Point)
 * ==========================================
 * 
 * 📖 목적: x와 y라는 숫자 타입의 속성을 가지는 객체의 형태를 정의합니다.
 * 🏗️ 구조: x, y 두 개의 숫자 필드로 구성됩니다.
 * 🎯 학습포인트: TypeScript의 인터페이스(interface)를 사용하여 데이터의 구조를 강제하는 방법을 배웁니다.
 */

// export: 이 인터페이스를 다른 파일에서도 사용할 수 있도록 공개합니다.
export interface Point {
  x: number; // x: x축 좌표를 나타내는 숫자 값입니다.
  y: number; // y: y축 좌표를 나타내는 숫자 값입니다.
}
```

## 🔍 상세 분석

### 문법 포인트
-   `export`: 모듈 시스템에서 해당 인터페이스를 외부로 내보내 다른 파일에서 `import`하여 사용할 수 있게 합니다.
-   `interface`: TypeScript에서 객체의 구조를 정의하는 데 사용되는 키워드입니다. 컴파일 시점에는 사라지며, 코드 작성 시 타입 체크를 도와줍니다.

### 실무 포인트
-   `Point`와 같이 자주 사용되는 구조를 인터페이스로 정의해두면, 함수나 클래스에서 매개변수나 반환 값의 타입을 명시할 수 있어 코드의 안정성과 가독성이 크게 향상됩니다.
