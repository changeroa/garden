## 📝 핵심 정리
현재 화면(캔버스)이 월드 좌표계의 어느 부분을, 어떻게 보여주고 있는지를 정의하는 핵심 데이터 구조입니다.

## 💻 코드 예제 (완전 주석)

```typescript
/**
 * ==========================================
 * [기능명]: 뷰포트 (Viewport)
 * ==========================================
 * 
 * 📖 목적: 화면의 상태(크기, 보고 있는 위치, 줌 레벨)를 하나의 객체로 관리합니다.
 * 🏗️ 구조: 화면의 너비/높이, 줌 레벨, 그리고 화면의 중심이 월드 좌표계의 어느 지점을 보고 있는지를 나타내는 center로 구성됩니다.
 * 🎯 학습포인트: 복잡한 상태를 하나의 인터페이스로 묶어 관리하는 방법을 배웁니다.
 */

export interface Viewport {
  x: number;      // x: 뷰포트의 시작 x 좌표 (일반적으로 0)
  y: number;      // y: 뷰포트의 시작 y 좌표 (일반적으로 0)
  width: number;  // width: 뷰포트의 너비 (픽셀 단위)
  height: number; // height: 뷰포트의 높이 (픽셀 단위)
  zoom: number;   // zoom: 확대/축소 배율. 1이면 기본, 2면 2배 확대.
  
  // center: 뷰포트의 중심이 월드 좌표계의 어느 점을 가리키고 있는지를 나타냅니다.
  center: { x: number; y: number }; 
}
```

## 🔍 상세 분석

### 로직 포인트
-   `width`, `height`: 캔버스의 픽셀 크기를 나타냅니다. 이 값이 커지면 더 넓은 영역을 렌더링합니다.
-   `zoom`: 사용자가 휠을 돌리거나 핀치 줌을 할 때 이 값이 변경됩니다. `zoom`이 커질수록 월드 좌표계의 더 작은 영역이 `width` x `height` 픽셀에 매핑되므로 확대되어 보입니다.
-   `center`: 사용자가 지도를 드래그(패닝)할 때 이 값이 변경됩니다. 뷰포트가 월드 공간을 돌아다니는 효과를 줍니다.

### 실무 포인트
-   뷰포트 상태를 하나의 객체로 관리하면, 상태 저장 및 복원이 용이해집니다. 예를 들어 현재 화면 상태를 저장했다가 나중에 그대로 다시 보여주는 기능을 쉽게 구현할 수 있습니다.
