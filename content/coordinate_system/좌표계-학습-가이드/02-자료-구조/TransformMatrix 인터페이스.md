## 📝 핵심 정리
2D 그래픽 변환(이동, 크기, 회전 등)을 수학적으로 표현하는 3x3 행렬의 구조를 정의합니다.

## 💻 코드 예제 (완전 주석)

```typescript
/**
 * ==========================================
 * [기능명]: 2D 변환 행렬 (Transform Matrix)
 * ==========================================
 * 
 * 📖 목적: 2D 변환에 필요한 6개의 핵심 값(a, b, c, d, e, f)의 타입을 정의합니다.
 * 🏗️ 구조: 3x3 행렬에서 실제로 변환에 영향을 주는 6개 요소로 구성됩니다.
 * 🎯 학습포인트: 행렬이 코드에서 어떻게 표현되는지 이해합니다.
 * ℹ️ 정보: 이 코드에서는 Float32Array(9)로 행렬을 직접 다루지만, 개념적으로 이 인터페이스와 동일한 역할을 합니다.
 */

// 3x3 행렬:
// | a c e |
// | b d f |
// | 0 0 1 |

export interface TransformMatrix {
  a: number; // x축 크기 (scaleX)
  b: number; // y축 기울기 (skewY)
  c: number; // x축 기울기 (skewX)
  d: number; // y축 크기 (scaleY)
  e: number; // x축 이동 (translateX)
  f: number; // y축 이동 (translateY)
}
```

## 🔍 상세 분석

### 문법 포인트
-   `CoordinateTransform` 클래스에서는 `TransformMatrix` 인터페이스를 직접 사용하지 않고, `viewMatrix: Float32Array(9)`를 사용합니다. 이는 WebGL과 같은 그래픽 API에 데이터를 직접 전달하기에 더 효율적이기 때문입니다.
-   `Float32Array`는 타입이 지정된 배열로, 32비트 부동소수점 숫자를 담습니다. 일반 JavaScript 배열보다 성능이 좋습니다.

### 로직 포인트
-   `a` (`m[0]`) 와 `d` (`m[4]`)는 각각 x축과 y축의 크기(스케일)를 조절합니다.
-   `e` (`m[6]`) 와 `f` (`m[7]`)는 각각 x축과 y축의 위치(이동)를 조절합니다.
-   `b` (`m[1]`, `m[3]`) 와 `c` (`m[2]`, `m[5]`)는 회전이나 기울이기에 사용되지만, 이 예제에서는 0으로 설정되어 있어 해당 변환은 사용되지 않습니다.

### 실무 포인트
-   DOM의 `transform: matrix(a, b, c, d, e, f)` CSS 속성이나 Canvas 2D 컨텍스트의 `setTransform(a, b, c, d, e, f)` 메서드는 이 6개의 값을 직접 사용합니다. 이 구조를 이해하면 CSS 변환과 Canvas, WebGL 렌더링을 모두 같은 원리로 다룰 수 있습니다.
