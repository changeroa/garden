# 브라우저 통합

## 🎯 이 개념의 위치
-   **상위:** [.[05-고급-주제/05-고급-주제]]
-   **하위:** [.[05-고급-주제/DevicePixelRatio 처리]], [.[05-고급-주제/DOM 이벤트 리스너]], [.[05-고급-주제/Canvas 경계 관리]]
-   **관련:** [.[03-변환-엔진/CoordinateTransform 클래스]]

## 📖 개념 설명
순수한 수학적 계산을 넘어, `CoordinateTransform` 클래스가 실제 브라우저 환경과 어떻게 상호작용하는지를 다룹니다. 브라우저의 특성(고해상도 디스플레이, 창 크기 변경, 페이지 스크롤)에 대응해야만 정확한 좌표 변환이 가능합니다.

## 🗺️ 하위 구성요소
-   [.[05-고급-주제/DevicePixelRatio 처리]]: 레티나 디스플레이와 같은 고해상도 화면에서 선명한 렌더링을 하기 위한 처리 방법을 배웁니다.
-   [.[05-고급-주제/DOM 이벤트 리스너]]: `ResizeObserver` 등을 사용하여 캔버스의 크기 변경을 감지하고, 뷰포트를 업데이트하는 방법을 알아봅니다.
-   [.[05-고급-주제/Canvas 경계 관리]]: `getBoundingClientRect`를 통해 페이지 내에서 캔버스의 정확한 위치와 크기를 파악하는 방법을 학습합니다.

## 💡 실무 연결점
이러한 브라우저 통합 기능이 없다면, 좌표 변환은 페이지를 스크롤하거나 창 크기를 조절했을 때, 혹은 고해상도 모니터에서 볼 때 모두 깨지게 됩니다. 안정적인 인터랙티브 애플리케이션을 만들기 위해 필수적인 요소입니다.
