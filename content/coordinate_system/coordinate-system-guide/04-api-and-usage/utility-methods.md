# 유틸리티 메서드

## 🎯 이 개념의 위치
-   **상위:** [.[04-api-and-usage/04-api-and-usage]]
-   **이전:** [.[04-api-and-usage/delta-transform-api]]

## 📖 개념 설명
직접적인 좌표 변환 외에, 좌표계 정보를 활용하여 유용한 계산을 수행하는 보조 메서드들입니다.

## 🗺️ 하위 구성요소
-   `isPointVisible`: 특정 월드 좌표 지점이 현재 화면에 보이는지 여부를 확인합니다.
-   `getWorldBounds`: 현재 화면에 보이는 월드 좌표계의 사각형 영역을 계산합니다.
-   `calculateZoomToFit`: 특정 월드 영역이 화면에 꽉 차게 보이도록 하는 최적의 줌 레벨을 계산합니다.

## 💡 실무 연결점
-   **렌더링 최적화**: `isPointVisible`을 사용하여 화면 밖에 있는 객체는 아예 렌더링하지 않음으로써(컬링, Culling) 성능을 크게 향상시킬 수 있습니다.
-   **미니맵(Minimap)**: `getWorldBounds`를 호출하여 현재 화면이 전체 맵의 어느 부분을 보고 있는지 미니맵에 표시할 수 있습니다.
-   **초기 뷰 설정**: `calculateZoomToFit`을 사용하여 특정 콘텐츠나 검색 결과가 화면에 보기 좋게 나타나도록 초기 뷰포트를 설정할 수 있습니다.
