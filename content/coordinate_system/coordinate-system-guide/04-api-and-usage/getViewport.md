# getViewport

## 🔗 연결
-   **상위:** `[[03-transform-engine/coordinate-transform-class]]`
-   **이전:** `[[04-api-and-usage/getInverseViewMatrix]]`
-   **관련:** `[[02-data-structures/viewport-interface]]`, `[[04-api-and-usage/updateViewport]]`

## 📝 핵심 정리
현재 클래스가 가지고 있는 뷰포트(Viewport) 상태 객체를 반환합니다.

## 💻 코드 예제 (완전 주석)

```typescript
/**
 * ==========================================
 * [기능명]: 뷰포트(Viewport) 가져오기
 * ==========================================
 * 
 * 📖 목적: 현재의 뷰포트 상태(중심 좌표, 줌 레벨 등)를 외부에서 조회할 수 있도록 합니다.
 * 🏗️ 구조: 내부의 뷰포트 객체를 복사하여 반환합니다.
 * 🎯 학습포인트: 내부 상태를 외부에 노출할 때, 복사를 통해 원본을 보호하는 캡슐화 원칙을 배웁니다.
 */
public getViewport(): Viewport {
  // 스프레드 문법(...)을 사용해 내부 viewport 객체의 복사본을 만들어 반환합니다.
  return { ...this.viewport };
}
```

## 🔍 상세 분석

### 로직 포인트
-   **방어적 복사(Defensive Copy)**: `{ ...this.viewport }`와 같이 객체를 복사해서 반환하는 것은 매우 중요한 부분입니다. 만약 `return this.viewport;` 와 같이 원본 참조를 그대로 반환하면, 이 함수를 호출한 외부 코드에서 실수로 객체의 속성(`viewport.zoom = 5` 등)을 변경했을 때 `CoordinateTransform` 클래스 내부의 상태가 오염됩니다. 이는 추적하기 어려운 버그의 원인이 됩니다.
-   복사본을 제공함으로써, 외부에서는 현재 상태를 읽을 수만 있고, 상태를 변경하고 싶을 때는 반드시 `updateViewport` 메서드를 통해서만 가능하도록 강제할 수 있습니다. 이는 클래스의 상태를 일관성 있게 관리하는 데 도움을 줍니다.

### 실무 포인트
-   현재 줌 레벨이나 중심 좌표를 UI에 표시해야 할 때 이 함수를 사용합니다. (예: "현재 줌: 2.5x")
-   현재 뷰포트 상태를 로컬 스토리지나 서버에 저장하여, 나중에 사용자가 다시 방문했을 때 보던 화면을 그대로 복원해주는 기능을 구현할 때 사용됩니다.
