# 🛠️ 서비스와 셀렉터: 조수와 렌즈

[[3. State Management - The Single Source of Truth|상태(Slice)]]가 모든 것을 소유하고 결정하지만, 모든 로직을 직접 수행하지는 않습니다. 복잡한 계산이나 데이터 변환은 '조수'에게 맡기고, 상태를 다양한 방식으로 보여주는 '렌즈'를 사용합니다.

### `ExplorerService`: 상태 없는(Stateless) 조수

`ExplorerService`는 레스토랑의 '전문 요리사'와 같습니다. 주방 매니저([[3. State Management - The Single Source of Truth|Thunk]])가 "이 재료(`FsNode[]`) 받아서, 이름순으로 정렬하고, 숨김 파일은 빼 줘" 라고 시키면, 그 일만 정확히 수행하는 역할입니다.

**핵심 원칙: Stateless (상태가 없다)**

- 서비스는 `this.files = []` 같은 내부 상태를 가지면 안 됩니다.
- 동일한 입력에 대해서는 항상 동일한 출력을 반환하는 **순수 함수(Pure Function)**의 모음이어야 합니다.
- 이렇게 하면 서비스 로직을 테스트하기가 매우 쉬워집니다.

```typescript
// src/features/file-explorer/services/ExplorerService.ts

// 상태를 갖지 않는 순수 함수들의 모음
export const ExplorerService = {
  // Provider가 준 노드 배열을 Slice가 원하는 정규화된 형태로 변환
  normalizeNodes(nodes: FsNode[], parentId: string | null): { byId: { [id: string]: FsNode }, childIds: string[] } {
    // ... 변환 로직 ...
  },

  // 정렬 함수
  sortNodes(nodes: FsNode[], sortBy: 'name' | 'mtime', order: 'asc' | 'desc'): FsNode[] {
    // ... 정렬 로직 ...
  },

  // 필터 함수
  filterNodes(nodes: FsNode[], filters: { query: string }): FsNode[] {
    // ... 필터링 로직 ...
  }
};

// Thunk 안에서 이렇게 사용됩니다.
const rawNodes = await provider.list(path);
const { byId, childIds } = ExplorerService.normalizeNodes(rawNodes, parentId);
dispatch(addNodes({ byId, childIds }));
```

### `Selectors`: 상태를 바라보는 렌즈

`Selector`는 스토어의 '날 것' 그대로의 상태를 가져와, UI 컴포넌트가 사용하기 좋은 형태로 가공해주는 함수입니다. 마치 다양한 색안경(렌즈)을 통해 세상을 보는 것과 같습니다.

**왜 필요한가?**

- **파생 데이터(Derived Data)**: "현재 선택된 폴더의 자식 노드들 중에서, `.md` 파일만, 이름순으로 정렬해서 보여줘" 같은 복잡한 요구사항을 처리합니다.
- **성능 최적화**: `reselect` 같은 라이브러리를 사용하면, 셀렉터는 입력값(상태)이 바뀌지 않는 한, 복잡한 계산을 다시 하지 않고 이전에 계산했던 결과를 즉시 반환(**메모이제이션, Memoization**). 이는 불필요한 리렌더링을 막아 성능을 크게 향상시킵니다.

```typescript
// src/features/file-explorer/state/selectors.ts
import { createSelector } from 'reselect';

// 기본 셀렉터: 스토어에서 필요한 부분만 추출
const selectNodesById = (state: RootState) => state.fileExplorer.nodes.byId;
const selectActiveDirId = (state: RootState) => state.fileExplorer.activeDirId;
const selectFilters = (state: RootState) => state.fileExplorer.filters;

// 메모이제이션된 셀렉터
export const selectVisibleNodesInActiveDir = createSelector(
  [selectNodesById, selectActiveDirId, selectFilters], // 입력 셀렉터들
  (nodesById, activeDirId, filters) => { // 계산 함수
    if (!activeDirId) return [];

    const activeDir = nodesById[activeDirId];
    if (!activeDir || !activeDir.childIds) return [];

    console.log("💥 이 로그는 입력값이 바뀔 때만 찍힙니다!");

    let visibleNodes = activeDir.childIds.map(id => nodesById[id]);
    
    // 필터링과 정렬 로직 적용 (ExplorerService 함수 사용 가능)
    visibleNodes = ExplorerService.filterNodes(visibleNodes, filters);
    visibleNodes = ExplorerService.sortNodes(visibleNodes, 'name', 'asc');

    return visibleNodes;
  }
);

// UI 컴포넌트에서 이렇게 사용
const visibleNodes = useSelector(selectVisibleNodesInActiveDir);
// 이제 visibleNodes가 바뀔 때만 이 컴포넌트가 리렌더링됩니다.
```
