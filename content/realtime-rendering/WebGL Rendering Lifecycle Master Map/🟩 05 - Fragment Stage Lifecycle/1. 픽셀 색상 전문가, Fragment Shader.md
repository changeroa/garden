
# 1. 픽셀 색상 전문가, Fragment Shader

Fragment Shader(또는 Pixel Shader)는 렌더링 파이프라인에서 가장 창의적이고 예술적인 작업을 수행하는 단계입니다. GPU 안에서 일하는 수많은 **'픽셀 색칠 전문가'**라고 생각할 수 있습니다. 이 전문가의 임무는 [[🟥 04 - Rasterization Lifecycle/1. 도형을 픽셀 격자로 채우기|래스터화 단계]]에서 결정된 각각의 픽셀 후보(프래그먼트)를 어떤 색으로 칠할지 최종 결정하는 것입니다.

> **핵심: 렌더링 성능에 가장 큰 영향을 미치는 곳. 모든 화려한 시각 효과가 여기서 탄생한다.**

---

### 1. 언제 호출될까? (호출 시점)

-   [[🟥 04 - Rasterization Lifecycle/2. 불필요한 부분은 그리지 않기|깊이 테스트]] 등 모든 테스트를 통과하여 "최종적으로 화면에 그려져야 할" 픽셀 후보(프래그먼트) 하나하나에 대해 **개별적으로, 그리고 병렬적으로** 실행됩니다.
-   예를 들어, 800x600 해상도의 화면을 가득 채우는 삼각형을 그린다면, 이 색칠 전문가는 약 480,000번 호출되어 각 픽셀의 색을 계산합니다. 이 계산량이 많을수록 GPU는 바빠집니다.

### 2. 무엇을 입력받을까? (Inputs)

색칠 전문가는 작업을 위해 [[🟨 03 - Vertex Stage Lifecycle/4. 정점 처리 전문가, Vertex Shader|정점 처리 전문가]]가 남긴 **'보간된 꼬리표(Varying)'**를 주요 힌트로 사용합니다.

-   **보간(Interpolation)된 Varying 값**: 이 값이 바로 프래그먼트 셰이더의 마법의 핵심입니다. 정점 셰이더가 각 꼭짓점에 대해 계산한 값(색상, 텍스처 좌표 등)이 픽셀의 위치에 따라 자동으로 부드럽게 섞여서 전달됩니다.
    -   `in vec2 v_texcoord;`: 꼭짓점들의 텍스처 좌표가 보간된 값. 이 좌표를 이용해 텍스처(이미지)의 어느 부분을 읽어올지 결정합니다.
    -   `in vec3 v_normal;`: 꼭짓점들의 법선 벡터가 보간된 값. 부드러운 조명과 그림자 효과를 만드는 데 사용됩니다.
    -   `in vec4 v_color;`: 꼭짓점들의 색상이 보간된 값. 자연스러운 그라데이션 효과를 만듭니다.

-   **`gl_FragCoord`**: 현재 색칠하고 있는 픽셀의 실제 화면 좌표 `(x, y, z)` 정보를 담고 있는 유용한 내장 변수입니다.

### 3. 무엇을 출력할까? (Outputs)

-   색칠 전문가의 유일하고 가장 중요한 임무는, 현재 담당한 픽셀의 **최종 색상**을 결정하여 보고하는 것입니다.
-   `out vec4 fragColor;` 와 같이 출력 변수를 선언하고, 여기에 RGBA(빨강, 초록, 파랑, 투명도) 값을 계산하여 할당해야 합니다.

    ```glsl
    // 텍스처에서 색상 정보를 가져옵니다.
    vec4 textureColor = texture(u_sampler, v_texcoord);
    
    // 조명 계산 등을 수행합니다...
    // ...

    // 최종적으로 이 픽셀은 이 색이야! 라고 결정하여 출력합니다.
    fragColor = textureColor;
    ```

-   이렇게 결정된 색상 값은 다음 단계인 [[🟧 06 - Blending Lifecycle/1. 새로운 색과 기존 색을 섞는 공식|블렌딩(Blending)]]으로 넘어가, 프레임버퍼에 이미 그려져 있던 색상과 혼합되어 최종적으로 화면에 기록됩니다.
