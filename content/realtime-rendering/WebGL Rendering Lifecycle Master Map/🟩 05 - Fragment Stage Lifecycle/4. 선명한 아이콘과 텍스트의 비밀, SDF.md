
# 4. 선명한 아이콘과 텍스트의 비밀, SDF

SDF(Signed Distance Field, 부호 있는 거리 필드)는 확대하거나 축소해도 깨지지 않는 아주 선명한 아이콘, 텍스트, 도형을 렌더링하는 현대적인 핵심 기술입니다. 일반 비트맵 이미지와는 전혀 다른 방식으로 모양을 저장하고 표현합니다.

> **비유: 모양의 '등고선 지도'와 같습니다. 각 지점의 색상이 아닌, 경계선까지의 '최단 거리'를 기록한 지도입니다.**

---

### SDF란 무엇일까? (등고선 지도)

-   **일반 이미지 (비트맵)**: 각 픽셀에 "이 픽셀은 빨간색이야", "저 픽셀은 투명이야" 와 같이 색상 정보를 직접 저장합니다. 그래서 확대하면 픽셀이 네모낳게 깨져 보입니다.

-   **SDF 텍스처**: 각 픽셀(또는 텍셀)에 색상 대신, 모양의 **경계선까지의 최단 거리**를 저장합니다.
    -   모양의 **안쪽**에 있으면 **음수** 거리 값
    -   모양의 **바깥쪽**에 있으면 **양수** 거리 값
    -   모양의 **경계선**에 정확히 위치하면 **0**

이 '거리 지도' 정보만 있으면, 우리는 언제든지 원래 모양을 훨씬 높은 품질로 복원할 수 있습니다.

### SDF로 그림 그리기 (등고선 지도로 해안선 그리기)

마치 등고선 지도를 보고 해수면(고도 0)을 기준으로 육지와 바다를 구분하여 칠하는 것과 같습니다.

1.  Fragment Shader에서 SDF 텍스처를 읽어, 현재 픽셀의 거리 값(`dist`)을 가져옵니다.
2.  `dist`가 0보다 작거나 같으면 모양의 안쪽(육지), 0보다 크면 바깥쪽(바다)입니다.
3.  경계선을 부드럽게 표현하기 위해 `smoothstep` 함수를 사용합니다.

    ```glsl
    // SDF 텍스처에서 거리 값을 읽어옵니다.
    float dist = texture(u_sdf_texture, v_texcoord).r;

    // dist가 -0.05보다 작으면 0(투명), 0.05보다 크면 1(불투명),
    // 그 사이는 부드럽게 보간하여 안티에일리어싱 효과를 줍니다.
    float alpha = smoothstep(-0.05, 0.05, dist);
    ```

### `fwidth`와의 결합: 궁극의 선명함

위 예제처럼 `0.05`라는 고정된 값으로 경계선을 부드럽게 만들면, [[🟩 05 - Fragment Stage Lifecycle/3. 해상도에 구애받지 않는 경계선 만들기|확대/축소 시 두께가 변하는 문제]]가 발생합니다. 여기서 [[🟩 05 - Fragment Stage Lifecycle/3. 해상도에 구애받지 않는 경계선 만들기|스마트 브러시 `fwidth`]]가 등장하여 문제를 해결합니다.

```glsl
// SDF 텍스처의 값은 보통 0~1 범위로 정규화되어 있으므로, 0.5를 경계선으로 사용합니다.
float dist = texture(u_sdf_texture, v_texcoord).r - 0.5;

// 스마트 브러시: 현재 1픽셀에 해당하는 거리 값의 변화량을 계산합니다.
float width = fwidth(dist);

// 경계선(0)을 중심으로, 현재 줌 레벨에서의 '1픽셀 두께'만큼만 부드럽게 처리합니다.
float alpha = smoothstep(-width, width, dist);

// 최종 색상과 계산된 알파 값을 결합하여 출력합니다.
fragColor = vec4(u_color, alpha);
```

-   **결과**: 이 기법을 사용하면, 폰트를 아무리 크게 확대해도 벡터 그래픽처럼 완벽하게 깔끔한 곡선을 유지하고, 아이콘을 아주 작게 줄여도 뭉개지지 않는 놀라운 결과물을 얻을 수 있습니다.
-   우리가 매일 보는 스마트폰 UI나 웹 페이지의 고품질 텍스트와 아이콘 대부분이 바로 이 SDF 기술로 렌더링됩니다.
