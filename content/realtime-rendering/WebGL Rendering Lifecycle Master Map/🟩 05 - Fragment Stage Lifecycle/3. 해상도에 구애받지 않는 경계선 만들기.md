
# 3. 해상도에 구애받지 않는 경계선 만들기

그래픽을 렌더링할 때 흔히 겪는 문제 중 하나는, 카메라를 확대하면 선이 굵어지고 축소하면 너무 얇아지거나 깨지는 현상입니다. `fwidth`라는 마법 같은 함수는 이 문제를 해결하고, 어떤 해상도나 거리에서도 항상 일정한 두께의 선명한 선을 그릴 수 있게 해주는 핵심 기술입니다.

> **비유: 줌 레벨에 따라 자동으로 굵기가 조절되어 항상 일정한 선을 그어주는 '스마트 브러시'와 같습니다.**

---

### `dFdx`, `dFdy`: 내 이웃 픽셀은 어떤 값일까?

`fwidth`를 이해하려면 먼저 `dFdx`, `dFdy`를 알아야 합니다. GPU는 보통 픽셀들을 2x2 그룹으로 묶어서 처리하는데, 이 덕분에 아주 효율적으로 이웃 픽셀의 정보를 알아낼 수 있습니다.

-   `dFdx(p)`: "내 바로 **오른쪽**에 있는 픽셀의 `p` 값은 내 `p` 값과 얼마나 차이 나지?" 를 계산합니다.
-   `dFdy(p)`: "내 바로 **아래쪽**에 있는 픽셀의 `p` 값은 내 `p` 값과 얼마나 차이 나지?" 를 계산합니다.

이 값들을 '스크린 공간에서의 미분값(Derivatives)'이라고 부릅니다.

### `fwidth`: 스마트 브러시의 본체

-   `fwidth(p)`는 `abs(dFdx(p)) + abs(dFdy(p))`와 같습니다.
-   이것을 쉽게 풀어서 말하면, **"어떤 값 `p`가 화면에서 1픽셀만큼 움직이는 동안 총 얼마나 변하는가?"** 를 의미합니다.
-   즉, `fwidth`는 현재 렌더링 환경에서 **'1픽셀에 해당하는 값의 변화량'**을 알려주는 아주 유용한 정보입니다.

### `fwidth`를 이용한 자동 경계선 두께 조절 원리

-   **문제 상황**: 안티에일리어싱을 위해 `smoothstep(0.4, 0.6, value)`처럼 경계선의 부드러운 폭을 `0.2`라는 고정된 값으로 설정했다고 가정해 봅시다.
    -   **화면 확대 시**: 1픽셀이 차지하는 영역이 넓어지므로, 고정된 `0.2`라는 폭은 상대적으로 너무 좁아져 경계선이 다시 날카로워집니다.
    -   **화면 축소 시**: 1픽셀이 차지하는 영역이 좁아지므로, `0.2`라는 폭은 상대적으로 너무 넓어져 경계선이 흐릿하게 뭉개져 보입니다.
    -   이것이 바로 [[🧩 09 - Rendering Lifecycle 디버깅 체계/Rendering Lifecycle 디버깅 체계|확대/축소 시 경계 두께가 변하는 문제]]입니다.

-   **`fwidth`를 이용한 해결**: 스마트 브러시를 사용하는 것입니다. **"경계선의 부드러운 폭을 항상 현재 줌 레벨에서의 1픽셀 두께만큼으로 유지해줘!"**

    ```glsl
    // value는 0을 기준으로 안과 밖이 나뉘는 값 (예: SDF 값)
    float value = ...;

    // 스마트 브러시: 현재 1픽셀에 해당하는 value의 변화량을 계산
    float width = fwidth(value);

    // 0을 중심으로 항상 1픽셀 너비만큼의 부드러운 경계를 만듦
    float alpha = smoothstep(-width, width, value);
    ```

-   **결과**: 이렇게 하면 카메라가 물체에 가까이 가든 멀리 가든, 렌더링 해상도가 바뀌든 상관없이, 우리 눈에는 **항상 일정한 두께의 선명하고 부드러운 경계선**이 보이게 됩니다. 이는 [[🟩 05 - Fragment Stage Lifecycle/4. 선명한 아이콘과 텍스트의 비밀, SDF|SDF 렌더링]] 같은 현대적인 기법의 핵심 기술입니다.
