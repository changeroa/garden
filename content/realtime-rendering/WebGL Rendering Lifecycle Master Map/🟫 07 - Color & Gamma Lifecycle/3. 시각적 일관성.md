
# 3. 시각적 일관성

[[🟫 07 - Color & Gamma Lifecycle/2. 감마 보정 타이밍|올바른 감마 워크플로우]]를 적용하는 궁극적인 목표는 애플리케이션의 모든 시각적 요소가 의도한 대로, 그리고 일관되게 보이도록 하는 것입니다. 감마 불일치는 미묘하지만 인지할 수 있는 톤의 어긋남을 유발합니다.

---

### 1. CSS 색과 WebGL 색 차이의 원인

-   **CSS 색상**: 브라우저는 CSS로 지정된 색상(예: `#FF0000`, `rgb(255, 0, 0)`)을 해당 운영체제와 디스플레이의 색상 프로파일에 맞춰 **sRGB**로 해석하고 렌더링합니다. 즉, CSS 색상은 감마 보정이 적용된 색입니다.

-   **WebGL 렌더링**: 만약 WebGL에서 감마 보정 워크플로우를 전혀 사용하지 않는다면, 모든 계산과 출력이 [[🟫 07 - Color & Gamma Lifecycle/1. 선형 vs sRGB|선형(Linear) 공간]]에서 이루어집니다. 이 선형 값을 디스플레이가 sRGB로 해석하여 그대로 출력하면, 중간 톤이 실제보다 어둡게 보입니다.

-   **결과**: CSS로 지정한 `background-color: #808080` (회색)과 WebGL에서 `vec3(0.5, 0.5, 0.5)`로 렌더링한 회색은 나란히 놓았을 때 **서로 다른 밝기**로 보이게 됩니다. WebGL 쪽이 훨씬 어둡게 보입니다. 이것이 [[🧩 09 - Rendering Lifecycle 디버깅 체계/Rendering Lifecycle 디버깅 체계|색이 다르게 보이는]] 대표적인 사례입니다.

### 2. 감마 불일치가 만드는 톤 어긋남 (탁함, 헤이즈)

-   **조명 및 블렌딩 오류**: 선형 공간에서 처리되어야 할 조명 계산이나 [[🟧 06 - Blending Lifecycle/1. Blend Equation & Factors|블렌딩]]이 sRGB 공간에서 잘못 수행되면, 중간 톤이 손실되고 전체적인 색상 대비가 부자연스러워집니다.
    -   **어두운 부분**: 필요 이상으로 어두워져 디테일이 묻힙니다.
    -   **밝은 부분**: 너무 빨리 흰색으로 포화되어 하이라이트 디테일이 사라집니다.
    -   **블렌딩 경계**: [[🟧 06 - Blending Lifecycle/2. Premultiplied Alpha 흐름|Premultiplied Alpha]]를 사용하지 않을 경우, 반투명 경계에 어두운 후광(fringe)이 생깁니다.

-   **시각적 결과**: 씬 전체가 마치 안개가 낀 것처럼 **탁해(muddy) 보이거나**, 대비가 너무 강해 **거칠어(harsh) 보일 수 있습니다.**

### 3. 일관성 확보 방안

1.  **전체 워크플로우에 감마 보정 적용**: 텍스처 입력부터 최종 프레임버퍼 출력까지, 파이프라인 전체에 걸쳐 일관된 [[🟫 07 - Color & Gamma Lifecycle/2. 감마 보정 타이밍|감마 워크플로우]]를 적용하는 것이 가장 중요합니다.

2.  **sRGB 확장 기능 활용**: `EXT_sRGB`와 sRGB 프레임버퍼를 사용하여 GPU가 하드웨어 레벨에서 자동으로 감마 변환을 처리하도록 합니다.

3.  **상수 색상 변환**: 셰이더에 하드코딩된 색상 값(예: `vec3(1.0, 0.0, 0.0)`)도 sRGB 색상으로 간주하고, 다른 텍스처와 동일하게 선형 공간으로 변환해주어야 합니다. (물론, 이 변환은 워크플로우 자동화 시 함께 처리될 수 있습니다.)

    ```glsl
    // CSS에서 #FFCC00 와 같은 색을 셰이더로 전달했을 때
    uniform vec3 u_srgb_color;

    void main() {
        vec3 linear_color = pow(u_srgb_color, vec3(2.2));
        // ... 이 linear_color를 가지고 조명 계산 수행 ...
    }
    ```

이러한 원칙을 따르면 포토샵에서 본 텍스처 색상, CSS로 지정한 UI 색상, WebGL 3D 씬의 색상이 모두 조화롭게 어우러지는 시각적 일관성을 달성할 수 있습니다.
