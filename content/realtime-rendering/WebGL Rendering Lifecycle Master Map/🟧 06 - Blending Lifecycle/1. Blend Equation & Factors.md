
# 1. Blend Equation & Factors

> **핵심: 픽셀 색이 이미 그려진 색과 섞이는 마지막 연산 단계.**

Blending은 [[🟩 05 - Fragment Stage Lifecycle/1. Fragment Shader 호출 시점|Fragment Shader]]가 계산한 **Source** 색상(새로 그릴 픽셀)을 프레임버퍼에 이미 있는 **Destination** 색상(기존 픽셀)과 어떻게 혼합할지 결정하는 과정입니다. `gl.enable(gl.BLEND)`를 통해 활성화할 수 있습니다.

---

### 1. 기본 혼합 방정식 (Blend Equation)

WebGL의 기본 블렌딩 방정식은 다음과 같습니다.

`FinalColor = (SourceColor * SourceFactor) + (DestinationColor * DestinationFactor)`

-   **SourceColor**: Fragment Shader가 출력한 `fragColor`.
-   **DestinationColor**: 프레임버퍼에 이미 그려져 있는 픽셀의 색상.
-   **SourceFactor / DestinationFactor**: 각 색상을 얼마나 반영할지 결정하는 가중치. 이 Factor들은 `gl.blendFunc()`를 통해 지정합니다.

### 2. `gl.blendFunc(srcFactor, dstFactor)`

`blendFunc`는 Source와 Destination에 각각 어떤 Factor를 곱할지 지정합니다.

#### 일반적인 알파 블렌딩 (Normal Alpha Blending)

가장 흔하게 사용되는 반투명 효과를 위한 설정입니다.

`gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA);`

-   **`gl.SRC_ALPHA`**: SourceFactor를 Source의 알파 값으로 사용합니다. `(SourceColor.rgb * SourceColor.a)`
-   **`gl.ONE_MINUS_SRC_ALPHA`**: DestinationFactor를 `1.0 - Source의 알파 값`으로 사용합니다. `(DestinationColor.rgb * (1.0 - SourceColor.a))`

**최종 방정식**:
`FinalColor = (SourceColor * SourceColor.a) + (DestinationColor * (1.0 - SourceColor.a))`

-   **의미**: 새로 그릴 픽셀이 불투명할수록(Source Alpha가 1에 가까울수록) Source 색상을 더 많이 사용하고, 투명할수록(Source Alpha가 0에 가까울수록) 기존 Destination 색상을 더 많이 유지합니다.

### 3. 주요 Blend Factor 종류

| Factor | 값 | 설명 |
| :--- | :--- | :--- |
| `gl.ZERO` | `0` | 색상을 사용하지 않습니다. |
| `gl.ONE` | `1` | 색상을 100% 사용합니다. (덧셈 혼합/Additive Blending에 사용) |
| `gl.SRC_COLOR` | `SourceColor` | Source의 색상 값을 Factor로 사용. (곱셈 혼합) |
| `gl.DST_COLOR` | `DestinationColor` | Destination의 색상 값을 Factor로 사용. |
| `gl.SRC_ALPHA` | `SourceColor.a` | Source의 알파 값을 Factor로 사용. (일반 알파 블렌딩) |
| `gl.ONE_MINUS_SRC_ALPHA` | `1 - SourceColor.a` | `1 - Source 알파` 값을 Factor로 사용. (일반 알파 블렌딩) |
| `gl.DST_ALPHA` | `DestinationColor.a` | Destination의 알파 값을 Factor로 사용. |
| `gl.ONE_MINUS_DST_ALPHA` | `1 - DestinationColor.a` | `1 - Destination 알파` 값을 Factor로 사용. |

-   `gl.blendFuncSeparate()`를 사용하면 RGB 채널과 Alpha 채널에 대해 각각 다른 블렌딩 함수를 적용할 수도 있습니다. 이는 [[🟧 06 - Blending Lifecycle/2. Premultiplied Alpha 흐름|Premultiplied Alpha]] 처리 시 중요합니다.
