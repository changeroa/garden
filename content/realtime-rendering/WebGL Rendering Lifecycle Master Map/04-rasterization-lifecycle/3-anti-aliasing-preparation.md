
# 3. Anti-Aliasing 준비

Anti-Aliasing(AA)은 픽셀 기반 디스플레이의 한계로 인해 발생하는 계단 현상(Aliasing 또는 "Jaggies")을 완화하여 그래픽 경계선을 부드럽게 만드는 기술들의 총칭입니다. 래스터화 단계는 AA를 위한 데이터를 준비하는 중요한 역할을 합니다.

---

### 1. MSAA (Multi-Sample Anti-Aliasing)

-   **기본 동작**: 가장 널리 쓰이는 AA 방식입니다.
    1.  **다중 샘플링**: 래스터화 시, 픽셀당 하나의 중심점만 테스트하는 대신, 여러 개의 하위 샘플 위치(예: 4x MSAA의 경우 픽셀당 4개)를 설정합니다.
    2.  **커버리지 마스크(Coverage Mask) 생성**: 각 하위 샘플이 삼각형에 포함되는지 여부를 테스트하여 비트마스크를 생성합니다. 예를 들어 4x MSAA에서 3개의 샘플이 포함되면, 커버리지 마스크는 `1101`과 같은 형태가 됩니다. 깊이 테스트도 샘플별로 수행됩니다.
    3.  **셰이더는 한 번만 실행**: 해당 픽셀이 삼각형에 하나라도 걸쳐있다면, [[05-fragment-stage-lifecycle/1. Fragment Shader 호출 시점|Fragment Shader]]는 **픽셀당 단 한 번만** 실행하여 색상을 계산합니다.
    4.  **최종 색상 혼합**: 셰이더가 계산한 색상을 커버리지 마스크를 기반으로 기존 배경색과 혼합합니다. `1101` 마스크의 경우, 커버리지는 75%이므로 `최종색 = 셰이더색 * 0.75 + 배경색 * 0.25` 와 같이 계산되어 경계가 부드러워집니다.

-   **장점**: Fragment Shader 호출 횟수를 늘리지 않으면서 높은 품질의 AA를 제공하여 성능 효율이 좋습니다.
-   **단점**: 셰이더 내부에서 발생하는 Aliasing(예: 텍스처의 반짝임)은 해결하지 못합니다.

### 2. SSAA (Super-Sample Anti-Aliasing)

-   **기본 동작**: 가장 간단하지만 가장 무거운 방식입니다.
    1.  **고해상도 렌더링**: 실제 화면 해상도보다 훨씬 큰 해상도(예: 2배 큰 버퍼, 4배 많은 픽셀)로 렌더링을 수행합니다.
    2.  **다운샘플링(Down-sampling)**: 렌더링이 완료된 고해상도 이미지를 화면 해상도에 맞게 축소합니다. 이 과정에서 여러 픽셀의 색상이 평균화되면서 경계가 부드러워집니다.
-   **장점**: 가장 높은 품질의 결과를 보여주며, 셰이더 내부의 Aliasing까지 모두 해결합니다.
-   **단점**: 픽셀 수가 4배(2x2 SSAA)로 늘어나므로, Fragment Shader 연산량과 메모리 사용량이 기하급수적으로 증가하여 성능 부담이 매우 큽니다.

### 메모리/성능 트레이드오프

| 기술 | Fragment Shader 실행 횟수 | 메모리 사용량 | 품질 | 주요 특징 |
| :--- | :--- | :--- | :--- | :--- |
| **No AA** | 1x | 1x | 낮음 | 계단 현상 발생 |
| **MSAA** | 1x | 높음 (샘플 수만큼) | 중간 | **성능과 품질의 균형.** 기하학적 경계선에 효과적. |
| **SSAA** | 높음 (샘플 수만큼) | 매우 높음 (샘플 수만큼) | 높음 | **최고 품질.** 모든 종류의 Aliasing에 효과적. 성능 저하 극심. |
