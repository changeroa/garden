
# 4. 정점 처리 전문가, Vertex Shader

Vertex Shader는 렌더링 파이프라인에서 우리가 직접 프로그래밍할 수 있는 첫 번째 단계입니다. GPU 안에서 일하는 수많은 **'정점(Vertex) 처리 전문가'**라고 생각할 수 있습니다. 이 전문가 한 명 한 명이 우리가 그리려는 모델의 정점 하나하나를 전담 마크합니다.

---

### 1. 언제 호출될까? (호출 시점)

-   CPU가 `gl.drawArrays()` 나 `gl.drawElements()` 같은 "그리기 시작!" 명령을 내리는 순간, GPU 안에 있는 수천수만 명의 정점 처리 전문가들이 각자 담당할 정점 하나씩을 붙잡고 **동시에, 병렬적으로** 작업을 시작합니다.
-   만약 1,000개의 정점으로 이루어진 3D 모델을 그린다면, 이 Vertex Shader 프로그램은 GPU 내부에서 정확히 1,000번 실행됩니다.

### 2. 무엇을 입력받을까? (Inputs)

전문가는 작업을 위해 두 종류의 정보를 받습니다: **'개별 정보(Attribute)'**와 **'공통 정보(Uniform)'**입니다.

-   **Attributes (`in` 키워드 사용)**: 각 정점마다 고유하게 주어지는 정보입니다.
    -   `in vec3 a_position;` // "너의 원래 위치는 여기야."
    -   `in vec2 a_texcoord;` // "네가 입을 옷(텍스처)의 이 부분을 사용해."
    -   이 정보들은 [[02-canvas-to-gpu-entry/3. GPU에 데이터 꾸러미 전달하기|VBO(재료 상자)]]에 담겨 전달됩니다.

-   **Uniforms (`uniform` 키워드 사용)**: 이번 그리기 명령에 포함된 모든 정점에게 공통적으로 적용되는 정보입니다.
    -   `uniform mat4 u_projectionMatrix;` // "모든 점들은 이 투영 행렬을 사용해."
    -   `uniform float u_time;` // "현재 애니메이션 시간은 3.5초야."

### 3. 무엇을 출력할까? (Outputs)

전문가의 작업 결과물은 **'최종 위치가 찍힌 좌표'**와 다음 공정으로 넘길 **'꼬리표(Varying)'**입니다.

-   **`gl_Position` (필수 출력)**: **Vertex Shader의 가장 중요한 임무입니다.**
    -   모든 변환 계산([[03-vertex-stage-lifecycle/1. 모델을 씬에 배치하고 카메라로 바라보기|모델, 뷰, 투영 행렬 곱셈]])을 마친 후, 정점의 최종 위치를 [[03-vertex-stage-lifecycle/2. 카메라에 보이는 영역만 남기기|클립 공간(Clip Space)]] 좌표로 계산하여 `gl_Position`이라는 특별한 변수에 반드시 저장해야 합니다.
    -   GPU는 이 `gl_Position` 값을 보고 다음 단계인 클리핑과 래스터화를 진행합니다.

-   **Varyings (`out` 키워드 사용)**: 다음 단계인 '색칠 전문가(Fragment Shader)'에게 전달할 정보를 담는 꼬리표입니다.
    -   `out vec2 v_texcoord;` // "내가 사용한 텍스처 좌표를 다음 전문가에게 전달해줘."
    -   `out vec3 v_world_normal;` // "조명 계산에 필요한 법선 벡터 정보도 넘겨줄게."

### 꼬리표의 비밀: 자동 보간 (Attribute Interpolation)

-   Vertex Shader가 출력한 꼬리표(Varying) 값은 Fragment Shader에게 그대로 전달되지 않습니다.
-   **비유**: 한쪽 끝 점이 빨간색이고 다른 쪽 끝 점이 파란색인 선을 그린다고 상상해 보세요. 우리는 두 점의 색만 알려줬지만, 그 사이는 자연스러운 보라색 그라데이션으로 채워져야 합니다.
-   **자동 보간**: GPU의 [[04-rasterization-lifecycle/1. Triangle Coverage Calculation|래스터라이저]]가 바로 이 역할을 합니다. 삼각형 내부의 각 픽셀에 대해, 세 꼭짓점의 꼬리표 값을 거리에 따라 자동으로 섞어서(보간하여) 부드러운 중간값을 계산해 줍니다.
-   이 보간된 값이 Fragment Shader의 입력으로 들어가기 때문에, 우리는 텍스처가 깨짐 없이 부드럽게 입혀지고, 조명이 자연스럽게 변하는 효과를 얻을 수 있습니다.
