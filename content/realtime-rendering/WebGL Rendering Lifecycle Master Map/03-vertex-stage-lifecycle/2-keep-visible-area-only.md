
# 2. 카메라에 보이는 영역만 남기기

[[03-vertex-stage-lifecycle/1. 모델을 씬에 배치하고 카메라로 바라보기|투영 행렬]]까지 곱해진 3D 공간의 점들은 이제 '클립 공간(Clip Space)'이라는 특별한 편집실로 들어옵니다. 이곳에서는 카메라의 뷰파인더에 보이지 않는 부분을 모두 잘라내고, 남은 부분을 표준 규격에 맞게 변환하는 중요한 작업이 이루어집니다.

---

### 1. 클리핑 (Clipping): 보이지 않는 부분 잘라내기

-   **비유**: 영화 편집자가 촬영된 필름에서 카메라 앵글 밖의 불필요한 부분이나 NG 장면을 잘라내는 과정과 같습니다.
-   **역할**: GPU는 카메라의 시야각과 시야 거리(Near/Far Plane)로 결정되는 육면체 모양의 시야(절두체, Frustum) 안에 들어오지 않는 모든 도형을 과감하게 잘라 버립니다.
    -   만약 삼각형의 일부만 시야에 걸쳐 있다면, GPU는 그 삼각형을 잘라서 보이는 부분만으로 새로운 삼각형을 만들어 냅니다.
-   이 클리핑 과정은 GPU 하드웨어에 내장된 기능이라 우리가 직접 코드를 짤 필요는 없으며, 매우 빠른 속도로 자동 처리됩니다.

### 2. NDC 변환: 표준 포맷으로 정규화하기

-   **비유**: 편집된 필름들을 어떤 종류의 영사기에서도 상영할 수 있도록, 업계 표준 포맷(예: MP4)으로 변환하는 과정과 같습니다.
-   **역할**: 클리핑을 마친 후, GPU는 제각각이었던 좌표들을 `w`라는 값으로 나누는 **'투시 나눗셈(Perspective Division)'**을 수행합니다.
-   이 마법 같은 과정을 거치고 나면, 화면에 보일 모든 점들의 좌표는 가로(x), 세로(y), 깊이(z) 모두 **-1에서 +1 사이의 값**을 갖는 깔끔한 정육면체 공간 안에 놓이게 됩니다.
-   이 표준화된 공간을 **NDC(Normalized Device Coordinates, 정규화된 장치 좌표)**라고 부릅니다.

    -   `(x: -1, y: -1)` 은 화면의 왼쪽 아래 모서리
    -   `(x: +1, y: +1)` 은 화면의 오른쪽 위 모서리
    -   `z` 값은 물체의 깊이 정보로 사용됩니다.

-   **장점**: 이제부터는 실제 화면 해상도나 비율에 신경 쓸 필요 없이, "화면 왼쪽 끝은 -1, 중앙은 0, 오른쪽 끝은 1" 이라는 일관된 표준 좌표를 사용할 수 있게 됩니다.

### 스케일과 바이어스 (Scale and Bias)

-   가끔은 `-1 ~ +1` 범위보다, 텍스처 좌표처럼 `0 ~ +1` 범위가 더 편리할 때가 있습니다.
-   이때는 아주 간단한 수학 공식을 이용해 범위를 쉽게 바꿀 수 있습니다.
    -   `바뀐좌표 = 원래좌표 * 0.5 + 0.5`
-   이 공식을 적용하면 `-1`은 `0`이 되고, `+1`은 `1`이 됩니다. 이처럼 좌표의 범위를 바꾸는 유용한 기술을 '스케일과 바이어스'라고 부르며, 그림자 효과 같은 고급 렌더링 기술에 자주 사용됩니다.
