
# 1. 렌더링 공장의 전체 조립 라인

WebGL 렌더링 과정을 거대한 **'디지털 그림 공장'**이라고 상상해 보세요. 이 공장은 3D 모델이라는 '원재료'를 받아서 화면에 표시될 '완제품 그림'으로 만들어내는 조립 라인(Pipeline)을 가지고 있습니다.

---

### 공장의 입출력 구조

-   **📥 입력 (원재료)**: 공장에 들어오는 원재료는 3D 모델을 구성하는 수많은 **점(Vertex)**들의 정보입니다. 각 점은 다음과 같은 데이터를 가집니다.
    -   **위치 (Geometry)**: 3D 공간 어디에 있는지 (`x, y, z` 좌표)
    -   **속성 (Attributes)**: 어떤 색을 가질지, 어떤 무늬(텍스처)를 입힐지 등의 추가 정보

-   **⚙️ 처리 (조립 라인)**: 원재료는 조립 라인을 지나며 단계별로 가공됩니다.
    1.  **[[🟨 03 - Vertex Stage Lifecycle/4. Vertex Shader의 생명주기|Vertex Shader]] (형태 가공)**: 점들의 위치를 3D 공간에서 2D 화면으로 옮깁니다.
    2.  **[[🟥 04 - Rasterization Lifecycle/1. Triangle Coverage Calculation|Rasterization]] (픽셀화)**: 점들로 이어진 삼각형을 아주 작은 '색칠 칸'인 픽셀로 변환합니다.
    3.  **[[🟩 05 - Fragment Stage Lifecycle/1. Fragment Shader 호출 시점|Fragment Shader]] (색칠)**: 각각의 픽셀 칸을 어떤 색으로 칠할지 최종 결정합니다.
    4.  **[[🟧 06 - Blending Lifecycle/1. Blend Equation & Factors|Blending]] (혼합)**: 만약 이미 칠해진 색 위에 반투명한 색을 덧칠한다면, 두 색을 자연스럽게 섞어줍니다.

-   **📤 출력 (완제품)**: 조립 라인의 모든 과정을 거치면, 마침내 우리가 화면에서 보는 한 장의 이미지, 즉 **프레임(Frame)**이 완성됩니다. 이 그림은 [[⚫ 08 - Framebuffer → Display Lifecycle/1. Framebuffer 구조|프레임버퍼(Framebuffer)]]라는 임시 저장소에 담겨 있다가 화면으로 전송됩니다.

### 각 공정의 역할과 병목 지점

'병목 지점'이란, 특정 공정에 일이 너무 많이 몰려서 전체 공장의 속도가 느려지는 현상을 말합니다.

| 공정 (스테이지)         | 역할                      | 주요 재료 (데이터)                   | 병목이 생기는 경우 (느려지는 원인)                                               |
| :---------------- | :---------------------- | :---------------------------- | :----------------------------------------------------------------- |
| **Vertex**        | 3D 모델의 점들을 2D 화면 좌표로 변환 | `vec3` (위치), `vec2` (무늬 좌표)   | - 모델이 너무 복잡해서 처리할 점이 수백만 개일 때<br>- 점마다 복잡한 계산을 할 때                 |
| **Rasterization** | 도형을 픽셀 단위로 분해           | 픽셀의 포함 여부                     | - 해상도가 4K처럼 매우 높을 때<br>- 반투명 객체가 많이 겹쳐서 같은 픽셀을 여러 번 칠할 때(Overdraw) |
| **Fragment**      | 각 픽셀의 최종 색상 계산          | `vec4` (빨강, 초록, 파랑, 투명도)      | - 매우 사실적인 조명이나 그림자 계산을 할 때<br>- 고화질 텍스처를 많이 사용할 때                  |
| **Blending**      | 계산된 색상을 기존 색상과 혼합       | `vec4` (새로운 색), `vec4` (기존 색) | - 유리창, 연기처럼 반투명한 레이어가 수십 개씩 겹칠 때                                   |
