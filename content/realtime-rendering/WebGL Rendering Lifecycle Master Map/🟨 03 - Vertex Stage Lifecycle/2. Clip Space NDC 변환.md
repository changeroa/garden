
# 2. Clip Space / NDC 변환

[[🟨 03 - Vertex Stage Lifecycle/1. Local → World → View 변환|투영 행렬(Projection Matrix)]]을 거친 정점은 Clip Space라는 특수한 좌표계에 놓이게 됩니다. 이 단계는 렌더링 여부를 결정하고, 최종 화면에 표시될 좌표를 정규화하는 중요한 과정입니다.

---

### 1. 클리핑 (Clipping)

-   **정의**: 카메라의 시야각(Field of View)과 시야 거리(Near/Far Plane)로 정의되는 절두체(Frustum) 바깥에 있는 기하학적 도형(삼각형 등)을 잘라내는 과정입니다.
-   **작동 시점**: Vertex Shader 실행 후, Rasterization 이전에 GPU 하드웨어에 의해 자동으로 수행됩니다.
-   **Clip Space**: 클리핑은 4차원 동차 좌표계인 Clip Space에서 이루어집니다. 정점의 `x, y, z` 좌표가 `-w`와 `+w` 범위 내에 있을 때만 화면에 보이게 됩니다.
    -   ` -w <= x <= w `
    -   ` -w <= y <= w `
    -   ` -w <= z <= w `
-   만약 삼각형의 일부만 이 범위에 걸쳐 있다면, GPU는 삼각형을 잘라 절두체 내부에 맞는 새로운 삼각형(들)을 생성합니다.

### 2. NDC(Normalized Device Coordinates) 변환

-   **정의**: 클리핑이 끝난 후, Clip Space 좌표를 `w` 값으로 나누어 정규화하는 과정입니다. 이를 **투시 나눗셈(Perspective Division)**이라고 합니다.
    -   `ndc_x = clip_x / clip_w`
    -   `ndc_y = clip_y / clip_w`
    -   `ndc_z = clip_z / clip_w`
-   **결과**: 변환된 NDC 좌표는 `x, y, z` 모두 `-1`에서 `+1` 사이의 값을 갖는 정육면체 공간에 놓이게 됩니다. 이 공간은 화면 비율이나 해상도와는 독립적입니다.
    -   `(x: -1, y: -1)`: 뷰포트의 왼쪽 아래
    -   `(x: +1, y: +1)`: 뷰포트의 오른쪽 위
    -   `z`: 깊이 값으로 사용됩니다. (`-1`=Near Plane, `+1`=Far Plane)

### Scale Bias

-   NDC 공간은 `-1`에서 `+1`의 범위를 갖지만, 텍스처 좌표나 다른 계산에서는 `0`에서 `+1`의 범위가 더 유용할 때가 많습니다.
-   이때 좌표 범위를 변환하기 위해 **Scale and Bias** 기법을 사용합니다.
-   `ndc_coord * 0.5 + 0.5` 수식을 적용하면, `[-1, 1]` 범위의 좌표가 `[0, 1]` 범위로 간단하게 매핑됩니다.
    -   `-1 * 0.5 + 0.5 = 0`
    -   `1 * 0.5 + 0.5 = 1`
-   이 기법은 섀도우 맵(Shadow Map) 등 다양한 고급 렌더링 기술에서 활용됩니다.
