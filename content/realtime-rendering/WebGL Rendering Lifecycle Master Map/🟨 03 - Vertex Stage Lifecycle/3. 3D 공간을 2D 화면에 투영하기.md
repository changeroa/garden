
# 3. 3D 공간을 2D 화면에 투영하기

[[🟨 03 - Vertex Stage Lifecycle/2. 카메라에 보이는 영역만 남기기|NDC]]라는 표준 포맷(-1에서 +1까지의 값)으로 변환된 좌표는 아직 추상적인 비율일 뿐, 실제 화면의 어느 픽셀에 표시될지는 모릅니다. **뷰포트 변환(Viewport Transform)**은 이 추상적인 좌표를 우리가 보는 화면의 실제 픽셀 위치로 옮겨주는 마지막 단계입니다.

> **비유: 영화관 영사기가 표준 규격의 필름(NDC)에 담긴 이미지를 거대한 스크린(화면 픽셀)에 꽉 채워 쏘는 과정과 같습니다.**

---

### `gl.viewport` 설정: 어디에 상영할 것인가?

-   `gl.viewport(x, y, width, height)` 함수는 GPU에게 "이 사각형 영역에 이미지를 꽉 채워서 상영해 줘!" 라고 알려주는 것과 같습니다.
-   `x, y`는 스크린의 시작 위치, `width, height`는 상영될 영역의 너비와 높이(픽셀 단위)입니다.
-   보통은 [[🟦 02 - Canvas → GPU 진입 단계/1. 그림을 그릴 캔버스 준비하기|준비된 캔버스]] 전체에 그림을 그리므로, `gl.viewport(0, 0, canvas.width, canvas.height)` 와 같이 설정합니다.

### NDC 좌표를 픽셀 좌표로 바꾸는 마법

-1에서 +1 사이의 NDC 좌표는 간단한 수학 공식을 통해 실제 픽셀 좌표로 변환됩니다.

1.  **범위 변경 (`ndc + 1`)**: `[-1, 1]` 범위를 `[0, 2]` 로 옮겨서 음수를 없앱니다.
2.  **정규화 (`/ 2`)**: `[0, 2]` 범위를 `[0, 1]` 로 만들어서, 좌표를 0%에서 100% 사이의 비율로 바꿉니다.
3.  **스케일링 (`* width`)**: 이 비율에 `viewport`의 너비(width)를 곱하여 실제 픽셀 위치를 계산합니다. (예: 50% 위치 * 800px 너비 = 400px)
4.  **오프셋 (`+ x`)**: 마지막으로 `viewport`의 시작 위치(x)를 더해 최종 좌표를 얻습니다.

> **`screen_x = (ndc_x * 0.5 + 0.5) * width + x`** (위 과정을 한 줄로 표현)

이 과정을 통해, 추상적이었던 NDC 좌표가 "왼쪽에서 400번째 픽셀"과 같이 우리가 이해할 수 있는 실제 위치로 바뀌게 됩니다.

### DPR과 뷰포트: 4K IMAX 스크린에 상영하기

-   **중요한 점**: `gl.viewport`는 CSS 픽셀이 아닌, **실제 물리적 픽셀**을 기준으로 작동합니다.
-   [[🟦 02 - Canvas → GPU 진입 단계/1. 그림을 그릴 캔버스 준비하기|DPR]]이 2.0인 레티나 디스플레이는 일반 화면보다 픽셀이 2배 더 촘촘합니다. 마치 일반 영화 스크린과 4K IMAX 스크린의 차이와 같죠.

-   **올바른 설정**: 300x150 CSS 크기의 캔버스가 DPR 2.0 화면에 있다면, 선명한 그림을 위해 실제 픽셀 해상도는 600x300이 됩니다. 따라서 `gl.viewport`도 **`gl.viewport(0, 0, 600, 300)`** 으로 설정하여, 이 촘촘한 600x300 픽셀 모두에 그림을 그려야 합니다.

-   **만약 잘못 설정하면?**: `gl.viewport(0, 0, 300, 150)`으로 설정하면, GPU는 600x300 크기의 도화지 중에서 왼쪽 아래 1/4 구석에만 작게 그림을 그리고 나머지는 비워둡니다. 의도치 않은 결과가 나오는 것이죠.

> **결론: `gl.viewport`의 크기는 항상 `canvas`의 실제 픽셀 너비/높이와 일치시켜야 합니다.**
